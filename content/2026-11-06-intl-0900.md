今日要点
OpenAI 推出网络安全模型 GPT-6 Cyber，先向另获批准的部分 Daybreak Red 客户经 API 和 Codex 开放，预备框架的网络安全等级定为 Critical。总裁 Greg Brockman 称企业销售已占收入多数，并说公司 2027 年有望具备上市条件。Anthropic 在美国向 Pro、Max 和 Ultra 推出只读的个人理财测试版，并公布对约 20.7 万次科研会话的测量。Google 正式发布 Gemini Omni 1.2 Flash，单条视频最长 15 秒，720p 每秒 0.07 美元，比上一代低 30%。Meta 在美国的 Muse 应用推出实时语音和表情头像。上一轮漏收：GPT-5.6 Cyber 已可在 AWS GovCloud（US-East）使用。

OpenAI
1. 推出网络安全模型 GPT-6 Cyber。11 月 5 日发布。模型面向授权的安全研究，用来发现漏洞、验证利用并准备修复，并经过专门训练，要求留在研究人员设定的范围内。预备框架把网络安全定为 Critical，高于 GPT-5.6 Cyber 的 High。先通过 API 和 Codex 向另获批准的部分 Daybreak Red 客户开放，随后扩大到全部 Daybreak Red；GPT-5.6 Cyber 则向所有 Daybreak Red 客户开放。官方称，研究人员用它在 Firefox 里发现 81 个此前未知的高危漏洞，另有 30 个已知问题被证明比原先评估的更严重，Mozilla 已开始合入修复。
背景：昨日简报公布的 Linux 内核漏洞运行，官方这次写明用的就是 GPT-6 Cyber。系统卡给出的能力分级与 GPT-6 Astra 相同：网络安全 Critical，生物与化学 High，AI 自我改进低于 High。
实际影响：模型 ID 为 gpt-6-cyber，输入可以是文字和图片。标准短上下文价格为每百万 token 输入 20 美元、缓存输入 2 美元、输出 100 美元。零数据保留的 API 客户一般必须使用 Private Safety Processing：相关请求的加密记录留在客户自己的存储里 30 天，OpenAI 员工看不到提示和回复；标准保留仍是默认。Daybreak Red 的 API 默认要求 IP 允许名单。另设 Daybreak Red for Critical Infrastructure，获批的关键基础设施防御方可以在防护仍在的前提下，对关键系统做授权测试。
https://openai.com/index/introducing-gpt-6-cyber/
https://www.theverge.com/ai-artificial-intelligence/1027599/openai-gpt-6-cyber-launch
2. Brockman 称企业销售已占收入多数，并认为 2027 年有望具备上市条件。11 月 4 日，他在华尔街日报于纳帕举行的科技会上说了这番话，TechCrunch 于 11 月 5 日报道。被问到明年能否准备好上市，他的回答是 I think so. Yes. 他称第三季度年化收入环比增长 70%，并把这归因于企业业务翻倍。企业收入现在占多数，此前大约只占三成；消费收入仍在增长。
背景：他说第一、第二季度比较艰难，智能体编程当时还不在外界讨论里，Codex 已经有了，但没人谈。
实际影响：会上没有宣布具体上市日期。他举了与摩根大通的合作，作为现在拿下的客户类型。
https://techcrunch.com/2026/11/05/openai-president-greg-brockman-says-company-could-be-ipo-ready-in-2027/
3. （补报）GPT-5.6 Cyber 进入 AWS GovCloud（US-East），上一轮简报漏收。11 月 4 日宣布。获批客户可以经 Amazon Bedrock 上的 Daybreak Red 使用。推理数据不用于训练模型，客户不必把 Daybreak Red 的数据交给 OpenAI。
背景：Daybreak 模型此前已在 Amazon Bedrock 提供，这次扩到 GovCloud（US-East），给在该环境里做关键任务的政府安全团队一条使用路径。
实际影响：需要 OpenAI 的 Daybreak Red 批准，再由 AWS 开通；批准本身不会自动打开模型。官方要求合格的安全人员在实施前复核发现和建议的修复。
https://openai.com/index/daybreak-red-aws-govcloud/

Anthropic
4. 在美国推出个人理财测试版。用户可以把银行、信用卡、贷款和投资账户连上 Claude，用自己的余额和交易记录提问。访问是只读的，不能转账、不能管理资金、也不能下投资指令。登录在 Plaid 里完成，Claude 看不到银行密码。本周起向美国的 Pro、Max 和 Ultra 逐步开放，网页、桌面、iOS 和 Android 都能用。
背景：TechCrunch 称，ChatGPT 在 5 月已经通过 Plaid 提供过同类功能。个人理财中心里的对话不用于训练模型；中心以外的对话仍按用户自己的隐私设置。
实际影响：免费版、Team 和 Enterprise 没有这项功能，也只能连接美国的银行，最多 16 家。Claude 能看到银行名称、账户名称、类型和末四位、余额和信用额度，以及最多 24 个月的交易。对投资、贷款和信用卡，它读余额和额度，不读持仓、成交、利率或条款。定时任务、Cowork、Claude Code 和 Claude Duet 用不了已连接的账户。
https://claude.com/resources/articles/introducing-personal-finance-in-claude
https://techcrunch.com/2026/11/05/claude-can-now-analyze-your-spending-with-its-new-personal-finance-tool/
5. 公布科学家如何使用 Claude 的测量。11 月 5 日的研究报告用隐私保护方法，看了 2026 年 8 月 2 日至 9 月 30 日消费者方案上的 207,049 次科研会话，其中 Claude（Chat 和 Cowork）128,914 次，Claude Code 78,135 次。相对各领域的研究者人数，计算机、数学和统计用得更多，健康和实验室类的物理科学用得更少。数据分析占 Claude 会话的 33.7%、Claude Code 的 48.1%，研究者花在这项上的时间占比是 27.6%。写作在 Claude 上占 32.0%，研究者时间占比是 16.0%。想法生成只占 Claude 会话的 4.2%、Claude Code 的 2.1%，而受访研究者把想法生成和数据采集排在对科学发现更重要的位置。
背景：样本是消费者方案上的会话，另有一份 Claude Science 的补充样本。Claude Science 上，想法生成所占比例大约是普通 Claude 的两倍。
实际影响：报告用一个简单模型做了情景推演。如果现有能力被广泛采用，部分领域的研究产出可能翻倍。如果 AI 承担全部非体力研究工作，计算机和统计的产出最多可能到 15 倍，化学和生物大约到 3 到 4 倍。在积极使用 AI 的受访者里，约 40% 预期模型到 2030 年可以独立完成整个研究项目。这些是推演，报告同时公布了上述用法测量。
https://www.anthropic.com/research/how-researchers-use-claude
6. Claude 控制台可以设置组织 IP 允许名单，企业版可以把成员从所有设备登出。11 月 5 日的平台说明写明，IP 允许名单处于测试版：不在名单上的地址访问受覆盖的服务会被拒绝，用来限制泄露的 API 密钥能从哪里调用。可以添加 IPv4、IPv6 地址或 CIDR，每个组织最多 1000 条。同一天，企业版管理员可以用 Admin API 把一名成员从所有浏览器、设备和受信任设备登出，并撤销该成员在本组织的 OAuth 令牌。请求需带 admin-user-sign-out-2026-10-08 测试版标头。
实际影响：成员仍留在组织里，可以马上重新登录。登出结束的是登录会话、受信任设备和本组织的 OAuth 令牌。
https://platform.claude.com/docs/en/release-notes/overview

Google
7. Gemini Omni 1.2 Flash 正式上线，单条视频最长 15 秒。11 月 5 日。Gemini API 和面向企业的 Gemini 正式可用，Google Cloud 提供预置吞吐量。视频从最长 10 秒增至 15 秒，时长可以按 1 秒一档在 3 到 15 秒之间指定。同一条片子可以多轮对话修改，例如换产品、背景、光线或画幅，不必整段重做。720p 每秒 0.07 美元，比 Omni 1.1 低 30%。可以先用 360p 或 720p 出草稿，再把选定的成片升到 1080p 或 4K。输出带不可感知的 SynthID 水印。
背景：上一代 Omni 1.1 最长 10 秒。1.2 加强了对人物、产品和风格参考的保持，口型和对多个说话人的区分也更清楚。
实际影响：开发者今天可以在 Gemini API 上用于生产。Gemini 应用里的 15 秒视频正在向 Google AI Ultra 订阅用户推出。Google Vids 里，有 Google 账号或 Workspace 订阅的人每月可以免费生成最多 3 条 15 秒视频。Flow 和 Google Ads 也能用。
https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemini-omni-1-2-flash/
https://blog.google/products-and-platforms/products/workspace/omni-1-2-flash-google-vids/

Meta
8. Muse 应用在美国推出实时语音和表情头像。11 月 5 日。手机、网页和 Mac 上，点右上角的电话图标即可开始说话，中途可以打断。头像会按对话的语气做表情和手势，也可以选择只听声音、把头像放在对话旁边，或全屏面对面。声音有数百种，可以随时更换。说话的同时，Muse 可以在后台继续处理要做的事。
背景：Connect 2026 上预览过这种实时对话。TechCrunch 称头像听得见用户，但看不见用户。
实际影响：语音和表情头像先在美国的 Muse 应用推出。与 Muse 的语音对话即将上到 AI 眼镜和 Muse Charm。
https://about.fb.com/news/2026/11/introducing-muse-ai-voice-expressive-avatars/
