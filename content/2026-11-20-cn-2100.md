腾讯混元
补报：开源 Hy4、Hy4-FP8 和预训练 Hy4 base
11月19日20:51，腾讯混元在 GitHub 写入开源说明、许可证和微调代码。新闻条目写，Hy4、Hy4-FP8 和预训练模型 Hy4 base 的权重放在 Hugging Face、ModelScope 和 GitCode。Hugging Face 上 tencent/Hy4、tencent/Hy4-FP8、tencent/Hy4-base 的最近更新时间是 11月20日11:05。IT之家 11:47、36氪 11:53 报道这次开源。语言主干总参数 770B，这个数不含视觉编码器和 DFly2；每个 token 激活文字 49B，视觉另计 1.23B。DFly2 草稿模型 3.3B。上下文 100 万（1,048,576）token，支持文字、图片和视频理解。Hy4 base 写明不是对话模型。Hy4 和 Hy4-FP8 的 reasoning_effort 默认 high，也可设 no_think。
背景：Hy4 正式版在 11月4日发布，当时没有放出这套权重。11月18日开源的是 Hy4 flash。GitHub 这次提交在 11月19日20:51，落在上一期 21:10 之前，上一期没有写。
实际影响：许可是 Tencent Hy License，不是 Apache 2.0。把模型做成给第三方远程调用的推理或微调服务，若全球连续 12 个月总收入超过 5000 万美元，或产品月活超过 1 亿，要另外取得书面许可；只在内部用、不把模型、衍生模型和输出给第三方，则不受这一条限制。部署示例用镜像 vllm/vllm-openai:hy4 或 lmsysorg/sglang:hy4，加载 tencent/Hy4-FP8，8 卡。许可咨询邮箱是 hy_partners@tencent.com。

腾讯
微信视觉公开 WeMM-Video 权重
11月20日，腾讯微信视觉公开 WeMM-Video。仓库写，这是中英双语的全模态模型，接收文字、图片、音频和视频并输出文字；视频可以连同原声一起用。有指令模式和思考模式。系列包含 2B、4B、9B 稠密模型和 35B-A3B 混合专家模型，并提供 FP8、AWQ、GGUF 和 NVFP4。训练数据约 1.2 万亿多模态 token。Hugging Face 上 WeMM-Video-35BA3B 的 BF16 提交时间是 11月20日11:57。GitHub 首次提交是 11月19日20:36，说明在 11月20日继续更新。模型许可写明覆盖 2026年11月20日的该系列。
实际影响：源代码是 Apache 2.0。各检查点的模型许可以 Hugging Face 模型卡为准。快速开始用 Python 3.12 和 transformers 加载 tencent/WeMM-Video-2B，需要 trust_remote_code。思考模式是在 apply_chat_template 里把 enable_thinking 设为 True。
