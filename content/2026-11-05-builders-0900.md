今日要点
Cat Wu 宣布加入 OpenAI，负责 Core Products 产品，将与 Tibo 等一起做 agent。开源开发工具团队 Pierre 整体并入 OpenAI，工具已支撑 Codex 部分能力。dots 推 iOS 大更新：通知内联回复、Share 到 dot、Action Button。Peter Steinberger 质疑个人 AI 额度限制，主张服务「代表项目的 agent」。

Cat Wu → OpenAI
1. Cat Wu（@_catwu）宣布加入 OpenAI，担任 Core Products 产品管理负责人。她写到尊重 OpenAI 证明 scaling、把 AI 带给超十亿人，以及相信好产品是使命核心；将与 @thsottiaux、产品团队和全公司一起，「build agents that have your back and your team’s, and keep you in control」。Tibo 转发欢迎：「Welcome Cat. Stoked to be building together soon.」
背景：昨日简报已报她上周五离开 Anthropic / Claude Code；本期是去向与职衔落地。
实际影响：Claude Code 核心产品人转入 OpenAI，直接对接 Codex/ChatGPT 产品线负责人 Tibo。
https://x.com/_catwu/status/2118137612577968402

Pierre → OpenAI / Codex
2. 开源开发者工具团队 Pierre（@pierrecomputer，含 Bootstrap 联合创始人 Jacob/@fat）宣布整体加入 OpenAI。Greg Brockman（@gdb）欢迎称：Pierre 的开源开发者工具「already power parts of codex today」，期待一起做「collaboratively building software with AI」。Codex 负责人 Tibo 转发：「Computers have RAM, right? Welcome Pierre. Let’s reinvent everything」。
背景：Pierre 做协作式代码/开发者工具；收购前其能力已进入 Codex 链路。
实际影响：OpenAI 把外部开源开发工具团队收进 Codex 一侧，强化「和 AI 一起写软件」的协作底座。

dots（OpenAI）iOS 更新
3. dots 团队发最新 App 更新，称近期专注更快、更稳。Tibo 确认「Dots just got a massive set of improvements」。具体包括：iOS 通知可内联回复 dot；系统分享可直接发给 dot；可用 iPhone Action Button 打开 dot；从通知点进加载更快；Gmail 链接可深链到邮件 App 内对应邮件。
背景：面向已在用 dots 的 iOS 用户；属产品迭代而非新模型。
实际影响：日常可在锁屏/通知栏与分享页直接驱动 dot，少一次打开 App。
https://x.com/_samirism/status/2118103057980690771
https://x.com/thsottiaux/status/2118139067636568305

Peter Steinberger
4. Peter Steinberger（@steipete）引用 Apple 下调员工 AI 日限额（工程师从约 300 美元降到 200、计划再降到 100 等报道）发问：个人额度限制是否还合理？能力变强后，更合理的是和一个「代表你的项目、持续跑环并演进代码库」的 agent 一起工作，人只做策展自动化；「The humans merely curate the automations.」
背景：企业侧仍普遍按 seat/人设日限额；agent 长任务与常驻项目 agent 正在抬头。
实际影响：把采购与配额讨论从「每人多少额度」转向「项目 agent 是否该有独立预算」。
https://x.com/steipete/status/2118116514700386439
