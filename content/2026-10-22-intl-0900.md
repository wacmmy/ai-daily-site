今日要点
Anthropic 开放主动式智能体 Claude Duet 的研究预览，并发布 2023 年以来 Claude API 的第一个新版本；Meta 三季报宣布设立无投票权 C 类股票为 AI 筹资，美国和加拿大已有超过 1000 万人用上 Muse。另补报 OpenAI 协调披露 PHP 关键漏洞。

OpenAI
1. ChatGPT 广告扩到另外 26 个国家，覆盖范围达到 89 国。新增包括阿根廷、智利、哥伦比亚、秘鲁等拉美市场，以及尼日利亚、南非、塞尔维亚、乌克兰、柬埔寨、孟加拉国和巴基斯坦。上线八个多月已有超过 10 万广告主；广告只出现在 Free 和 Go，Plus、Pro、Enterprise 仍无广告，回答与广告分开，也不受广告影响。
https://openai.com/index/chatgpt-ads-expands-26-new-countries/
https://www.theverge.com/ai-artificial-intelligence/1015567/chatgpt-ads-26-countries-rollout
2. （补报）OpenAI 于 10/21 15:00（上海）协调公开 PHP 关键漏洞，上一轮 21:00 简报漏收。Calif 用 GPT-5.6 Sol 在 Patch the Planet 中发现其中一处，Wiz 独立报告了这两处，维护者已发修复；OpenAI 放出核对受影响版本的 Codex 技能，并承诺通过 Daybreak for Frontline Defenders 向前线防御方提供 10 亿美元补贴额度。
https://openai.com/index/coordinated-disclosure-of-critical-vulnerabilities
https://www.theverge.com/tech/1015481/gpt-5-6-sol-was-used-to-identify-critical-php-flaw
3. API 可以限制项目能用的服务层级。10/21 的平台更新允许在项目设置里选择可用的 service tier，组织设置也可以一次性限制全部项目。企业可以用它把更贵的加速处理关在指定项目里。
https://developers.openai.com/api/docs/changelog

Anthropic
4. Claude Duet 研究预览开放。这是独立的主动式智能体应用，覆盖 iOS、Android 和 claude.ai：早上汇总要处理的事项，人离开后在自己的云端电脑上继续干活，发消息、付款、签字或删除前会先请示。研究预览面向美国 Pro 和 Max 候补，包含在现有套餐里，后台检查也计入用量；跑在 Claude Opus 5.5 上，Team 和 Enterprise 还不能用。
https://claude.com/resources/articles/claude-duet
https://www.cnbc.com/2026/10/21/anthropic-preview-of-claude-duet-personal-ai-agent-take-on-muse-dots.html
5. Claude Security 改为随代码变化持续扫描。企业版公开测试中，连上仓库后先做深度基线扫描，再按改动的风险和复杂度复查；修复合入后自动标为已修，问题再现会重新打开。可用包括 Claude Mythos 在内的全系列模型，不必另加网络验证计划；2026 年 12 月 31 日前连续两个月、每月 2.5 万美元用量额度，并提供 API 和 MCP。
https://claude.com/resources/articles/claude-security-now-scans-continuously-and-tracks-fixes
6. Claude API 发布版本 2026-10-21，这是 2023 年 6 月 1 日之后的第一个 API 版本。升级到新的 SDK 主版本（Python 2.0.0、TypeScript 1.0.0 等）后，请求默认走新版本，temperature、top_p、top_k 被移除，再传会返回 400；旧 SDK 仍走 2023-06-01。新 SDK 和 ant CLI 的许可证改为 Apache 2.0。
https://platform.claude.com/docs/en/release-notes/overview

Google Gemini
7. Docs 手机端上线语音成稿 Docs Live。Android 和 iOS 的 Google Docs 可以用说话把零散想法整理成结构化草稿，Gemini 会从 Gmail、云端硬盘、Chat 和网页取相关上下文。已开通 Gemini in Docs 的账号默认开启，快速发布和计划发布网域现在可用，覆盖 Business、Enterprise 的相应版本以及 Google AI Pro 和 Ultra。
https://workspaceupdates.googleblog.com/2026/10/create-structured-documents-using-just-your-voice-with-Docs-Live-in-Google-Docs-on-mobile.html

Meta
8. Meta 设立无投票权 C 类股票，并披露 Muse 规模。董事会批准公开交易的无投票权 C 类普通股，拟于 2027 年 1 月 19 日生效，按现有 A、B 类股票 1:1 发放股利，投票权不变，用于 AI 基建、员工薪酬和收购，同时维持创始人控制。2026 年资本开支指引收窄到 1350 亿到 1450 亿美元；Zuckerberg 在财报会上说，一个半月内美国和加拿大已有超过 1000 万人设立 Muse 个人智能体。
https://investor.atmeta.com/investor-news/press-release-details/2026/Meta-Reports-Third-Quarter-2026-Results/default.aspx
https://techcrunch.com/2026/10/21/meta-wants-to-pay-for-its-broad-ai-buildout-with-a-newly-created-class-of-stock/
