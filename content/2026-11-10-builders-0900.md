Dan Shipper / Every：Fable 5.2 day-zero vibe check
1. Dan Shipper（@danshipper）发帖：Anthropic 发布 Claude Fable 5.2，称「如果你有够野心的项目，这是范式级模型」。Every 团队早期试用里的例子：Kieran Klaassen 三天做出 Everycut（把他们常用的 Premiere、Descript 等能力收进一个带 agent 的视频剪辑器，并立刻用于内部 show-and-tell）；Jack Cheng 给一张幼儿凌乱游戏室照片，模型把真实玩具做成可玩赛车（鞋子当障碍、吸管杯当道具）；Mike 把研究做成纪录片——模型出采访题、他出镜回答、模型剪片，自称「职业生涯里最高产的三周」。他强调换工作方式：把大活丢给模型过夜或过周末，但要先说清楚什么叫「做完」——Mike 发现它可能写完还要再测一两天。代价：慢、吃 token；早期访问免费，按 API 价这些项目会很贵；比 Fable 5.1 便宜约 20%，但日常写作、邮件、来回快改代码他通常会换别的模型。Every 站点同日上线 Vibe Check 文《Fable 5.2 Is a Paradigm Shift—If You Know What to Do With It》。
背景：名单内 Claude 账号同日宣布 Fable 5.2 全付费档可用，Mythos 5.2 面向网络安全/生物医学等可申请；硬新闻线会另报产品发布，本期只收 builder 实测。
实际影响：有长周期、边界不清的大项目时可以按他的建议试「设目标+预算+验收，然后走开」；日常快迭代仍可先用更快更便宜的模型。

swyx / Anthropic 工程：1000 个 Fable agent 安全复现费马大定理形式化
5. swyx（@swyx）引用 Lance Martin（@RLanceMartin）帖：有人用费马大定理形式化当 Fable 5.2 发布演示，并说 AI Engineer Code 场还有更大计划。Lance 等在 claude.dev 发文《Safely scaling multi-agent teams with Claude Fable 5.2》：1000 个跑早期 Fable 5.2 的 agent，在无 Prove2Me、无研究员指挥下，用 shell/文件编辑/Lean/Git/共享 Postgres 等通用工具，28.7 小时复现了形式化证明；输出 token 约为此前数十个 agent+研究员 11 天那次的三分之一，证明长度约七分之一。每个 agent 在无外网沙箱里；分类器会先审每条 shell/编辑，另有离线监控。起初 helper 判 47/60 条陈述「预算内不可行」，lead 仍把人力挪到可做的题上，最终完成；最难的 Langlands–Tunnell 被拆成最多约 10 层、2418 个任务的树。作者称这是 toy experiment，不取代领域 harness；人类鼓励在「过早放弃」时仍有用。
背景：Anthropic 9 月已报过在 Prove2Me 上的费马形式化；本期是同一目标换「通用工具 + 安全边界 + 千级 agent」的复现实验。
实际影响：做多 agent 长程任务的人可对照其「沙箱无网 + 实时分类器 + 离线监控 + 共享 SQL 协调」栈；也可见 agent 会误判难度、需要重新分配人力。
