Claude：Meetings 开始向 Team / Enterprise 推送
1. Claude 官方账号（@claudeai）宣布推出 Claude Meetings：把 Claude 加进团队视频会议，它会跟着听，并在你们还在谈的时候开始写文档、白板和其他制品。它作为可见的参与者加入，可以用语音或聊天提问，让它开始写一份文档；默认用文字作答，调用已连接的工具前要得到许可。会后，纪要、待办、转写和它做出来的东西都会留在 Claude 里这次会议的页面上。目前先支持 Google Meet，其他会议平台稍后跟上；开始向 Team 和 Enterprise 计划推送公测。说明文还写：默认情况下，有组织外的人在邀请名单里时 Claude 不会进会，中途有外人加入会离开，管理员可以改这项设置；它保存转写、摘要和屏幕描述，不保存音频。公测期间，Team 和 Enterprise 的纪要与转写免费；会议中的回答也免费，除非调用了已连接的工具（会计入套餐用量）；会议里做出来的文档、白板等制品免费用到 2027 年 2 月 10 日。开启零数据保留（ZDR）、HIPAA 就绪配置或客户管理加密密钥（CMEK）的组织，公测期间暂不可用。Alex Albert（@alexalbert__）引用该帖说，现在要从 Claude 拿到好结果，很大程度上是找出它缺的上下文并补上；Meetings 是把剩下那几块带进来的一种办法，他们内部已经觉得很好用。Peter Yang（@petergyang）认为这事不小：很多会议只是先对齐、会后再做正事，如果 agent 能在会上把活做掉、同时帮团队对齐，会改变这个流程。
背景：11 月 11 日简报里，Claude 介绍 Whiteboards、Sheets 和交互式连接器时，只提过 Meetings「即将推出」；本期是正式开始推送。
实际影响：Team 计划默认就可以邀请 Claude 进会，管理员能关掉；Enterprise 需由管理员为全部或部分组织打开。目前只接 Google Meet，且要团队里大家都接受被转写。

Josh / Levie：Gemini 4 Hydrogen 上线，Box 评测称又快又准
2. Josh Woodward（@joshwoodward）发帖宣布 Gemini 4 Hydrogen：「给所有人的前沿智力」，已经进入 Gemini App，并称又快又聪明，是一次大跳跃。Google 官方博客把 Hydrogen 定位为日常编码和 agent 工作流的快速执行模型，而 Gemini 4 Carbon 和 Argon 仍负责更深、更长周期的推理。它已在 Google AI Studio 全档、Gemini API、Gemini for business、Gemini App、Google Search，以及付费的 Google AI Pro / Ultra 在 Google Antigravity 中推出；免费的 Gemini App 用户会在系统判断合适时，通过自动选模用到它。定价在整个 100 万 token 上下文窗口内保持统一：输入每百万 token 1.50 美元，输出每百万 token 7.50 美元。Aaron Levie（@levie）写，他们用 Box AI Complex Work Eval 做了早期测试，认为这是快模型的一次明显跃升：Hydrogen 比 Gemini 3.8 Flash 准确率高 5 个百分点，而且典型任务耗时不到一半，token 大约少 12%。评测覆盖金融、咨询、生命科学等企业文档上的复杂工作；他称 Hydrogen 很快会进入 Box AI Studio，客户可以用来搭自定义 agent。
背景：11 月 11 日简报已报过 Every 对 Gemini 4 Carbon 的实测；Hydrogen 是同一代里面向日常执行、覆盖面更广的一档，不是再发一个旗舰。
实际影响：要跑日常编码、迭代或企业文档 agent 的人，可以在 API、AI Studio 和 Gemini App 里直接试；看重速度和成本时，可对照 Levie 相对 3.8 Flash 的数字，以及官方统一单价。

Guillermo / Vercel：推出给 agent 用的 UI SDK
5. Vercel 官方账号宣布推出 UI SDK。Guillermo Rauch（@rauchg）写道：到了 agent 时代，框架、组件库和 shadcn 该怎么办？答案是再往下钻一层——删掉多余的部分，优化、加速、自动化。他把 UI SDK 比作 agent 即兴搭建新界面组件时的「x86 指令集」：agent 成了新的设计工程师，高层次、死板、绑死单一框架的抽象反而会卡住这套几乎不知疲倦的生成能力。这套 SDK 把可访问性、性能和一致性做成打包好的行为，省 token、少出错、少手工，同时不限制能生成什么样的界面。文档和仓库写明：这是一套给 agent 用的行为库，键盘导航、焦点、选择、关闭、弹出层、拖拽和所需的 ARIA 放在 `@ui-sdk/core`，并有 React、Vue、Svelte、Solid 和 Web Components 适配；目前是 beta。安装可用 `npm install @ui-sdk/react @ui-sdk/core`，再执行 `npx skills add vercel-labs/ui --skill ui-sdk` 把 skill 交给 agent。仓库说明里有一句：「不用担心你得学会怎么写这些。你的 agent 会写。而且我们把它们教得很好。」
背景：这和此前面向开发者的 AI Elements / 生成式 UI 不是同一层——UI SDK 把交互行为做成更底层的原语，让 agent 按任务生成界面，而不是只从固定组件目录里挑。
实际影响：要用 agent 生成自定义界面的人，可以给 agent 装这个 skill，从行为原语起步；接口和文档在公测阶段还可能改。

Amjad / Replit：Agent 可代为采购，并投放 Google 广告
6. Amjad Masad（@amasad）发帖：现在可以让 Replit Agent 为你的业务买东西，包括买广告来获客。Replit 同日的博客写了两件事。一件是 Agentic Commerce：用 Stripe 的 Link 和 Visa，让 Agent 按你对产品的了解去找货、准备结账，例如「给这个产品找 50 个运费箱，含运费不超过 75 美元」；最终金额要等你确认才会扣款。浏览商家网站由 Browserbase 提供的隔离浏览器子 agent 完成，不必为每家店单独对接；若需登录，你可以先接管再交还。结账时会停下，Agent 没有开口花钱的权限；付款期间会关掉 shell 和一般浏览，批准检查写在代码里，不交给模型自行决定。这项能力面向 Core 和 Pro 用户，先从美国开始，且仅限一次性购买。另一件是在 Replit 对话里做 Google 广告：可覆盖 Search、YouTube、Display、Discover 等，分析网站或应用、起草文案、生成图片并建议每日预算，由你审完再发布；因为应用往往就是 Agent 做的，它还可以加上转化跟踪，按注册和销售而不是只按点击来看效果。也可以让 Agent 协助创建并管理 Google Ads 账号。
背景：Replit 已能让 Agent 写应用、收款、注册公司和做 SEO；这次是把采购和投放广告也接进同一条工作流，但花钱这一步仍要人点头。
实际影响：在美国的 Core / Pro 用户可以让 Agent 代为准备一次性采购，并在确认金额后付款；想从 Replit 里跑 Google 广告的人，可以在对话里连上或新建广告账号，发布前仍需自己批准。

Nikunj：抓取 803 家公司子处理商名单，看 AI 原生公司在用什么
7. Nikunj Kothari（@nikunj）发帖：他抓取了 803 家公司的子处理商（sub-processor）名单，用来看 AI 原生公司实际在用哪些基础设施，并和今年 3 月那次对比。主要发现：44% 的公司列出了两家及以上模型供应商（3 月是 33%）；样本不大，但 Anthropic 的增速大约是 OpenAI 的两倍。有 86 对公司互相把对方列为子处理商，例如 Anthropic 与 Cloudflare、Vercel 与 SpaceXAI。33% 的公司列出了推理供应商（3 月是 22%），他认为 Modal 仍然很强。中国模型主要出现在视频相关（如字节），而不是文本——至少在这些名单上是这样。typesafeai 是突出的新名字，短期内从 0 出现在许多公司的名单里。他提醒：子处理商名单往往是滞后指标，但一旦写上去，就能比较有把握地确认这家公司确实在用。完整数据和图表在 deploygraph.com，欢迎反馈。
背景：这是他用同一方法做的更新，不是单家公司的产品发布；发帖时间在昨日简报窗口边缘，上一期未收入。
实际影响：想判断模型、推理和基础设施份额时，可以把子处理商名单当作滞后但可核验的信号；要看原始数据和图表，直接去 deploygraph.com。
