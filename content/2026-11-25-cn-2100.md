月之暗面 Kimi
Kimi Code CLI 更新到 2.8.0
11月25日20:41，Kimi Code CLI 发布 2.8.0。实验性提示预测要设 KIMI_CODE_EXPERIMENTAL_PROMPT_PREDICTION=1，按 Tab 或右方向键接受。设置里的 Lab 可以打开上下文用量，列出模型收到的每一项。kimi web 的 @ 菜单可以引用其他会话，也在 Lab 里打开。实验性的 fork 参数已去掉，Agent 和 AgentSwarm 不能再带着当前对话历史启动子代理。
Always Ask 下，静态判定为只读的 Bash 会自动通过；要继续逐条确认，加一条 ask 规则。会话会等到 MCP 初次连接结束，超时前发现的工具在这一轮里可用。上传的图片或视频读不回来时，改用本地原件重发。失败的回合可以在原地继续，不再插入一条 Continue。转到后台的命令不再把累计输出整段灌进上下文。
背景：11月24日的 2.7.3 加入了单条回复打分，并修复模型下线后打不开的会话。
实际影响：不设环境变量就没有提示预测。上下文用量和会话提及默认关着。稳定版桌面端这次没有发。
来源：https://github.com/MoonshotAI/kimi-code/releases/tag/@moonshot-ai/kimi-code@2.8.0

11月24日20:41起，AngelSlim 的 Hy4-flash-GGUF 继续上传文件：DFly 草稿头，21:17 起的 Q4_K_M_MTP_Q8_0 两个分片，22:40 起的 Prune25 两个分片。11月25日14:13至14:24写入 Strata 和 Mac 的中文说明。说明页列出五档：Q4_K_M 156.79 GiB，SPARK-4Bit 151.3 GiB，SPARK-4Bit-Fast 148.6 GiB，Q3_K 144.70 GiB，IQ2-AH 125.73 GiB。Mac mini M4 Pro 64GB 上，IQ2、MTP k=2、8K 上下文的解码速度写成 17.3 tok/s。

补报：开源多模态检索模型 OmniEVIE-4B
11月24日11:16，Hugging Face 建立 tencent/OmniEVIE-4B。12:16，GitHub 写入首次公开版本。这是腾讯 IMA 产品中心和优图实验室的 4.54B 模型，许可 Apache 2.0，覆盖文本、图像、视觉文档、视频和工具。每条记录最多 128 个 64 维 int8 向量，9472 字节，100 万条约 8.82 GiB。论文写单线程查询 100 万条用 54.2 毫秒、500 万条用 120.2 毫秒。命中可以回到页面区域或视频起止时间，索引和定位都不再另跑视频解析模型。11月25日14:16的提交只更新了 arXiv 链接。
背景：论文日期是 11月19日。权重和代码公开是 11月24日，落在上一期 21:04 之前，上一期没有写。
实际影响：权重、推理和索引代码可以下载，许可是 Apache 2.0。
来源：https://huggingface.co/tencent/OmniEVIE-4B
来源：https://github.com/Tencent/OmniEVIE

Bot 0.7.36：被截断的任务结果会标明截断
11月25日15:24合并，插件版本 0.7.36。任务结果写进回执时会被截到 4000 字，之前截完不说明。这一版在被截断的结果末尾补上已有的截断标记。短结果一个字不变。全文仍可以用 get_tasks 读回来。
