智谱 GLM
ZCode插件仓库加入官方生图和视频生成
11月12日21:11，智谱向zcode-plugins加入image-generation和video-generation，作者署名为Z.ai。生图工具generate_image用文字出一张图，或按一张不超过10 MiB的png、jpeg、webp参考图改图。视频工具generate_video可带最多9张参考图、3个参考视频、3段参考音频，或改用首尾帧，但不能和参考素材同时用；单次最多等约四分钟，未完成时用返回的task_id调get_video_result，每次generate_video都消耗额度。
背景：两个插件都要求已登录并连接Coding Plan（个人或团队）。只用API Key或Start Plan的连接不能用。账号要关联Z.ai并绑定手机号，海外账号绑定邮箱。
实际影响：模型、尺寸、时长、画幅和水印由服务端固定。安装或更新后要新建会话。本地文件和输出路径必须在工作区内，不会覆盖已有文件。
来源：https://github.com/zai-org/zcode-plugins

月之暗面 Kimi
Kimi Code 2.6.0发布，全屏折叠工具调用，会话创建时才写入profile
11月12日17:56，月之暗面发布Kimi Code 2.6.0。全屏模式把连续的工具调用和思考折成摘要行，模型自己加载的技能不再显示Activated卡片；要恢复逐条展开，在/settings里调整Tool call density和Thinking folding，或在tui.toml的[transcript]里把tool_call_density和thinking都写成ungrouped。服务端在创建会话时写入agent profile、模型和思考强度，提示请求不再接受profile，要改传agent_config.profile。
背景：11月10日的2.5.3是在模型还在输出时，插入的消息会打断当前请求。
实际影响：订阅改走turns、turns.removed、turns.failed、turn.*、item.*和notice帧，旧的transcript帧以及GET /sessions/{id}/transcript（含/ops、/plan、/user-messages）已去掉，subscribe_v2改为传agent_ids。撤销改为传入turn_id和可选的agent_id，返回removed_turn_ids。同一文件可以连续Edit，不必每次先重读。非SSH、非mosh的复制只进系统剪贴板，要保留OSC 52就设KIMI_CODE_CLIPBOARD_OSC52=1。
来源：https://github.com/MoonshotAI/kimi-code/releases/tag/@moonshot-ai/kimi-code@2.6.0

腾讯混元
hy-memory 2.0.16发布，业务库可选PostgreSQL，记忆可按原向量导回
11月12日14:19，hy-memory 2.0.16上传到PyPI。Working和Coding的经历、事实、原始轨迹和Coding版本链改走仓库接口，SQLite仍是默认，已有SQLite数据不会自动迁到PostgreSQL；PostgreSQL在可选的hy-memory[postgres]里。export_user_memories和import_user_memories导出一名用户的向量记忆，带上id和向量，再写回一个空库，包含L1_RAW、各种状态、演化指针和时间；没有向量的节点用当前嵌入服务重算，宽度不符、别人的节点或非空目标会被拒绝，失败会回滚。图不在这次导入里，要另外调用build_memory_graph。Qdrant也可以按一个集合前缀做扫描、重嵌和删除。
背景：11月10日的2.0.15限制了Kuzu缓冲池，并让同一进程里指向同一个文件的图存储共用一个数据库。
实际影响：要给不接受max_tokens的模型换字段，把LLMConfig.output_token_parameter或环境变量MEMORY_LLM_OUTPUT_TOKEN_PARAMETER设为max_completion_tokens，默认仍是max_tokens。stdio宿主可以把MEMORY_LOG_STREAM设为stderr，避免INFO和DEBUG进到标准输出。改一条经历或事实时如果嵌入失败，返回EMBEDDING_FAILED，旧内容和向量留在原地。
