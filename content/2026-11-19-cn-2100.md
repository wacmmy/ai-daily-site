补报：调用模型触发的服务端搜索和抓取不再另收工具费
价格页写明，自北京时间2026年11月18日12:00起，调用模型时触发的服务端搜索、网页抓取，工具调用本身不再计费。工具返回的结果会拼进模型上下文，按模型Token用量计费。会触发服务端搜索的是联网工具、Anthropic API的web_search、Responses API的web_search。独立的Search API（文字）和Fetch API仍是每1000次成功请求5元。
背景：11月18日简报只写了Harness 0.2.2-rc.5里，用DeepSeek模型时搜索不按次收费，并仍把Search API写成每1000次5元。价格页这条的生效时间是11月18日12:00，落在上一期窗口里，上一期没有写。
实际影响：走联网工具或上述web_search的请求，不再为每次搜索或抓取另付工具费，返回内容仍按Token计。单独调用Search或Fetch API的，价格仍是每1000次5元。

Kimi Code CLI 2.7.0发布
11月19日19:16，月之暗面发布Kimi Code CLI 2.7.0，这是正式版。新增Amazon Bedrock，配置里type写bedrock，并使用AWS_REGION。终端可以在一轮结束后实验性地预测下一条提示，打开方式是环境变量KIMI_CODE_EXPERIMENTAL_PROMPT_PREDICTION=1，用Tab或右方向键接受。设置里的Follow-up behavior选Steer后，回车会把消息插进正在跑的那一轮。/tasks可以看到正在跑的前台Agent。kimi server在不打开浏览器的情况下跑本地服务，加上--open才打开网页。另外给出kimi web --json，以及GET /api/v1/sessions/{session_id}/interactions、POST /api/v1/sessions/{session_id}:wait、GET /api/v1/kap.md。项目可以配置SSH主机，每台主机用自己的Kimi登录，也可以复制自定义模型供应商。
同一版还允许恢复已经在另一个客户端打开的会话。kimi -p里，以及subagent的timeout_ms设为0时，子Agent不再立刻超时。压缩请求不再超过Claude Opus 5和Haiku 5的输出上限。Vertex AI按Google ADC认证，并使用配置里的project和location。Bash子进程会带上KIMI_CODE_SESSION_ID和KIMI_CODE_WORKSPACE_ID。后台Bash被截断的输出不再出现损坏字符。实时裁剪、长回合折叠，或重放损坏的会话日志时，对话历史不再消失。
背景：11月17日23:15的2.6.3修了前台命令重复输出和停止钩子。
实际影响：还在调用/api/v2/mcp或/api/v2/sessions的要改到/api/v1。POST /api/v1/mcp/servers/{id}:restart已经去掉，MCP服务器和OAuth改到/api/v1/mcp。会话查询里的include_archive、archived_only、exclude_empty换成archived和has_prompt。分组视图、git元数据、id投影，以及批量archive、restore，都在/api/v1/sessions。

MiniMax Bot 0.7.31：重启后已收下的请求可以再发
11月19日13:17，MiniMax Code小应用MiniMax Bot记为0.7.31。宿主在没有页面可见时可以停掉插件的Node进程，而且没有回调。已经收下、还没有回复的请求，重启后停在聊天里：页面没有再发的入口，续跑接口也会拒绝。这一版对这种请求提供Continue with follow-ups，续跑接口也接受它。它不会自己重放，因为进程停之前那一轮可能已经跑过工具，要不要再发由用户决定。已经开始有回复的请求不走这条。当前页面刚发出去的请求，不会给自己画出续跑按钮。同一改动还收口了并发：同一条消息的恢复，和按同一个ID重试，不会各执行一次。
实际影响：关掉再打开MiniMax Code之后，卡在已发出但没有回复的那条，可以点继续，不必重打一遍。不点的话，它不会自动再跑。
