Vercel 让 Chat SDK agent 用 json-render 流式生成 Slack/Teams 原生卡片；Guillermo 称生成式 UI 将成主流 HAI。Nikunj 重发本机 Wrapped 2026：一条提示跑脚本，本地出 iMessage/WhatsApp 年度回顾。Thariq 观察到创作者工具开始内置 MCP，agent 与专业软件可接力协作。

Guillermo / Vercel：Chat SDK × json-render 生成式 UI
1. Vercel Changelog（2026-11-06）发布：Chat SDK agent 现可用 json-render 流式生成式 UI。agent 按类型化组件目录写出 JSON 规格，json-render 转成 Chat SDK card，各适配器再发成平台原生格式（Slack Block Kit、Teams Adaptive Cards）。目录覆盖表格、图表、按钮等，不必为每种消息形状单独写工具。streamCard 在根元素有内容时先发帖，再按约 500ms 间隔随模型输出更新；toCard 校验 props，超平台上限时可降级或拒绝。Guillermo 发帖称「Generative UI for conversational agents」，把 AI SDK + Chat SDK + json-render 串起来，「I believe this will become the dominant Human-Agent Interaction (HAI) paradigm」。
背景：此前 json-render 已能把受约束的 JSON 渲成 Web UI；本期是接到 Slack/Teams 等对话入口并支持流式卡片。
实际影响：做企业/社群 agent 的人可直接在聊天里出表、图、按钮，少维护一套按消息形态分叉的工具。
https://vercel.com/changelog/json-render-and-chat-sdk-agents

Nikunj：Wrapped 2026（本机短信年度回顾）
2. Nikunj（@nikunj）重发 texts wrapped / wrap2026.com：分析 iMessage、WhatsApp 与通话，一条终端命令（或交给 Claude Code / Codex）在 Mac 上跑完；宣称 100% 本地、无 AI（People with Claude 模式除外）、开源。站点提供组合脚本与分渠道脚本，提示词要求 agent 先检查脚本有无网络/写删文件再执行；需 Full Disk Access。输出约二十页可分享幻灯，联系人跨 App 合并。
背景：名单内 builder 的个人工具；面向年底「年度回顾」场景，并刻意做成「粘贴给 coding agent 即可跑」。
实际影响：Mac 用户可用本机 coding agent 一键出隐私友好的短信/通话回顾；也可对照其「agent 先审脚本再执行」的安全提示写法。
https://wrap2026.com

Thariq：创作者 App 内置 MCP
3. Thariq（@trq212）发帖：喜欢的一种模式是 Instagram Edits、Roblox Studio 这类创作者 App 自带 MCP，这样 agent 能先做一部分工作，高手再在自己熟悉的工具里协作并继续改。
背景：MCP 多被讨论成「agent 外挂工具」；他强调的是专业软件把 MCP 做成一等公民入口。
实际影响：做创作者/设计/编辑工具的人可考虑内置 MCP，让 agent 与人工同一工作区接力，而不是只导出到聊天。
