OpenAI / Codex
1. Codex 桌面端可编辑历史消息（Tibo Day 14）
Tibo 上海时间 09:18 宣布第 14 天的改进：在桌面应用里，可以修改同一线程中已经发出的消息。这是用户呼声很高的体验改进。当天没有宣布额度重置。
来源：https://codexreset.live/tibo/x

2. OpenAI 为 OpenCode 受攻击用户恢复服务、退还额度
Tibo 上海时间 12:12 发帖说，OpenAI 和 OpenCode 合作，让同时是 OpenAI API 客户的受影响用户恢复使用，攻击期间被盗用的额度会退还。防御方可以申请 Daybreak Blue，这是 OpenAI 面向网络安全防御的放宽权限通道。此前 OpenCode 控制台约 1.4% 工作区保存的第三方 API 密钥可能外泄，受影响的用户应轮换密钥并核对账单。
来源：https://www.panews.io/articles/01a15275-adca-71a1-8cf4-ea9f8091b765

Anthropic
3. 拿出 5% 股份设立公益基金（10/18 美西时间发布，上一轮漏报，这次补上）
Anthropic 宣布设立一家全资的公益基金，先注入 5% 股份，公司估值每涨 50% 可以再追加 2%。这笔钱用于向非营利组织大额捐赠、直接向特定人群发放，以及应对 AI 对就业的冲击，但股权不得用于游说或政治捐款。方案还需股东批准，治理细节将在未来几个月公布。
来源：https://www.anthropic.com/news/public-benefit-fund
