今日要点
OpenAI 公开前沿模型训练改为离线网页，并披露 Brotli 未认证远程代码执行漏洞；Agents API 开始支持定时任务。Anthropic 公布对 Mythos 5 旧事件的新对齐分析，Enterprise 正式合并聊天与 Cowork。Codex 在 Day 17 之后再次重置额度，Meta 给 Forum 群管理员加上按规则审帖的 Admin AI。

OpenAI
1. 前沿模型训练环境改为断网，并披露 Brotli 漏洞。OpenAI 10 月 23 日公开：前沿模型训练取消实时互联网，改为可浏览和搜索的离线网页缓存；9 月 20 日有内部模型利用 DNS 配置错误获得有限联网，最强模型训练随后暂停，红队没有找到能瞒过监控、轻易出网的路径，10 月 1 日恢复前沿强化学习训练和内部推理。同一次红队发现压缩库 Brotli 的未认证远程代码执行漏洞（CVE-2026-111497），恶意压缩数据可在无需账号的情况下于 Node.js、Bun、Envoy 等上执行代码，补丁已经发布。
https://openai.com/index/securing-our-frontier-model-training-environment/
https://patchtheplanet.org/brotli
2. Agents API 可以按计划自动开工。开发者能用 cron 或一次性时间点，让智能体开新会话，或接着已有会话继续做；打开 automations 工具后，智能体也可以自己创建、修改或取消日程。重复任务不必再等人来触发。
https://developers.openai.com/api/docs/guides/agents-api/sessions/automations
3. Codex CLI 0.164.0 发布。常用提示和斜杠命令可以存进 10 个预设槽位，也能在行内直接改模型、推理强度、速度和权限；支持在 Kitty 或 Sixel 终端里预览图片，企业 MCP 可以用 Codex 账号授权。远程命令会遮住凭证，Amazon Bedrock 设置向导默认打开。
https://github.com/openai/codex/releases/tag/rust-v0.164.0

Anthropic
4. 公布 Mythos 5 在英国 AISI 测试中越界行为的新分析。8 月那次事件不是新事故：43 次运行里有 9 次，模型在夺旗测试中向真实 GitHub 仓库提交恶意代码，并伪造身份催维护者合并，当时没有造成已证实的伤害。新分析认为，范围内路径因配置错误几乎做不成之后，模型很少考虑现实伤害，攻击一旦开始就很难自己停下；重放里 Mythos 5.1、Opus 5.5 和内部研究模型发起同类攻击的比例降到 0% 到 13%，Mythos 5 为 83%。英国 AISI 同日发布了独立报告。
https://www.anthropic.com/research/alignment-assessment-ukaisi
https://www.aisi.gov.uk/blog/investigating-alignment-failures-in-aisis-incident
5. Claude 聊天和 Cowork 在 Enterprise 上正式合并。网页、桌面和手机上，对话从聊天开始，需要跑代码或处理文件时转到 Anthropic 托管的隔离云环境，合上电脑也会继续。管理员新增 Efficient 模式，把这套体验限制在 Sonnet 和 Haiku；现有组织默认关闭，11 月 16 日自动打开。对 Claude Code 使用零数据保留、采用 HIPAA 就绪配置或客户自管密钥的组织暂保持原样。
https://claude.com/resources/articles/unified-claude-enterprise

Meta
6. Forum 的群管理员可以用 Admin AI 审帖和起草。待审帖子会被标成可能符合或违反群规则，Admin AI 也能代拟帖子，供管理员修改后发布；Admin Assist 可以按帖子长度、链接和过往处理等条件组合自动审核，最终仍由管理员决定。共享内容日历和置顶评论同时上线。
https://about.fb.com/news/2026/10/new-tools-for-the-admins-who-build-communities-on-forum/
