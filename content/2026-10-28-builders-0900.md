今日要点
Codex 负责人 Tibo 宣布 Day 22 并推 Terra；Guillermo Rauch 用开源模型复现跨 Firecracker 微虚拟机的 CPU 隐蔽通信；Amjad Masad 谈「Agent Habitat」与 Replit Cloud Agents；Aaron Levie 从 Anthropic S-1 看 Fortune 500 企业支出仍极低；Thariq 在做 AI-native macOS Dock；Claude 博客发药物研发早期进展；Garry Tan 谈客服全流程交给 agent 起草。

Thibault Sottiaux（Codex）
1. Day 22：Terra 回来了。他说这是第一款在写作、个性和对请求的细腻理解上明显更好的模型，电脑操作也强，在 API 和订阅上用量是 6.1 Sol 的 2 倍。Sam Altman 同日也发帖称 6.1 Terra 已上线，尤其看好电脑使用新时代。

Guillermo Rauch
2. 复现 OpenAI 关于用 CPU 做隐蔽通信的发现：在通用主机上开 2+ 个无外网的 Firecracker 微虚拟机，做成 cpu-chat。即便关掉 SMT、不用 KSM、租户钉在不同核上，仍能通过 CPU 争用、缓存驱逐时序、DRAM 带宽争用三种机制跨 CPU 聊天，延迟还不错。他强调这不同于可偷数据的侧信道；开源权重模型肯配合做这类安全分析，闭源模型常拒绝，可能反而妨碍把沙箱做对。
https://x.com/rauchg/status/2114770919436808572

Amjad Masad（Replit）
3. 「Agent Habitat」：公司架构几百年没大变，AI agent 会把执行层交给机器、人只做判断，走向自驾公司。Replit 在为此打地基，并引用 Marc Andreessen 把这次变迁放进计算史的文章。另发帖宣布 Replit Cloud Agents：可在任意代码库上跑、直接生成 PR，「Replit 是否用 Replit 建」从「差不多」变成「绝对是」。
https://x.com/amasad/status/2114760898225299721
https://x.com/amasad/status/2115129060267262190

Aaron Levie
4. 读 Anthropic S-1：平均 Fortune 500 客户在 Anthropic 上的花费不到其支出的 0.1%。他认为没有理由不能涨到 10–50 倍（仍只占 1–5%）。今天几乎没有公司在用 agent 做大量后台任务和无人触发的工作流；真正的跃迁要等企业为 agent 重写底层流程，这类用例吃 token 往往大两个数量级，也更贴近直接 ROI。
https://x.com/levie/status/2114761816199098587

Thariq
5. 个人实验：做一个 AI-native 的 macOS Dock，带写作、构建等自定义模式帮自己专注；agent 能改模式行为、加新模式，并用 jev 实时分类活动与通知再行动。后续又提到开源分发需要一种新方式——让人能用 agent 改，同时上游变更还能自动合入。

Claude / Anthropic
6. 博客《Early progress on accelerating drug development with Claude》（2026-10-27）：生命科学团队与 BigHat、BMS、Divergence Labs、Enveda、Generate Biomedicines、The Column Group 等六家深度合作，并自研部分项目；收购 Mithril Medicine 后，其创始人用 Claude 协调 11 个外部实验室，把一种肌营养不良候选疗法从想法做到小鼠有希望的结果不到 18 个月。仍多属临床前。
