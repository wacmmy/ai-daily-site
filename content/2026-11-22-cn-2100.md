Harness 更新到 0.2.3-alpha.2
11月22日11:19，DeepSeek 发布 Harness v0.2.3-alpha.1。19:00 发布 alpha.2，把 Node.js 要求改为 24.x 系列的 24.22.3 及以上，或 26.13.1 及以上。alpha.1 让插件市场可以添加 Git 仓库作为插件来源，私有仓库里的插件也能浏览和安装。新增实验性时间线插件，可查看智能体任务树、阻塞事项和进展报告。代码审阅页可以集中查看本人相关的 GitHub PR，并支持评审和合并 GitLab。可选连接器包括 Linear、Notion、腾讯文档、飞书、企业微信、腾讯会议和钉钉，在插件页连接或授权后可在对话里使用。Web 连接模式可以远程登录。MCP 支持 OAuth 授权和凭据自动刷新。
alpha.1 还把 Office 技能收成 /office，覆盖 Word、PowerPoint 和 Excel，旧的分格式命令和自定义配置要迁移。Computer Use 在 macOS 上统一系统键鼠输入授权，Windows 为实验性支持，并可通过 cua-mcp 以 MCP 服务器对外提供。Node PTC 默认在调用之间保留变量，Python PTC 不再支持。会话存储可以改用实验性 SQLite，需要手动打开，默认仍是 JSONL。个性化推荐插件改为默认开启。Cordis 同步到 4.0.0-rc.12，插件和自定义配置要按升级指南迁移。
背景：11月18日的 0.2.2-rc.5 让 DeepSeek 模型走服务端搜索，搜索不按次收费。这次是 0.2.3 的 alpha。功能在 alpha.1，alpha.2 只提高了 Node.js 版本下限。
实际影响：安装当前的 alpha.2，Node.js 需要 24.22.3 及以上（24.x）或 26.13.1 及以上。还在用 Python PTC 的要改到 Node PTC。自定义插件若读取会话状态、分支会话或授权，要按升级指南改。

ZCode 3.19.1 发布
更新日志写，3.19.1 发布于 2026年11月22日，页面没有写到钟点。工具升级期间旧版本可以继续用。可以指定回复语言，语音输入可以用快捷键开关。模型选择菜单支持搜索。分叉会话的标题会自动编号。应用崩溃后可以一键重启。选择立即发送时，前台 Agent 会转入后台继续跑。会话里新增或删除的技能马上生效，不用重开会话。内置 design 插件增加生图。子任务默认在后台运行。命令行单次执行会等后台任务完成再退出。文件链接可以带行号和区间，打开后定位并高亮。
日志里还有几处安全相关修复：iOS 项目识别不再执行项目内代码。钩子拦截提示不再带出命令里的密码等敏感信息。adb 命令只允许使用工作区内的可执行文件。
背景：上一版 3.18.2 的日期是 11月13日，当时加入语音输入、Worktree 和设计系统检查。
实际影响：升级过程中旧版本不会被打断。命令行跑子任务时，会等到后台任务结束再退出。识别 iOS 项目时不再执行项目目录里的代码。
