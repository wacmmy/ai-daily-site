今日要点：Kimi Code 2.4.0可以导入Claude Code和Codex的近期会话，计划模式改为必须人工确认。火山方舟Agent Plan的kimi-k2.7-code于今日14:00停止服务。MiniMax开源团队自用的MCode Stack，15个Skill可装进MiniMax Code。

月之暗面 Kimi
Kimi Code 2.4.0上线，可导入Claude与Codex会话
10月28日19:45，月之暗面发布Kimi Code 2.4.0。新增/import-sessions和kimi import-sessions，可导入最近15天或30天的Claude Code与Codex会话。计划模式改为只能手动开启，每份计划都要等人确认，代理不能自行进入计划模式，Never Ask也不再自动批准计划。同版支持流式输出时用Ctrl-O展开思考，网页和桌面端会话闲置30分钟后从内存卸出，Tower默认并发从16提高到256。从其他编程工具迁过来时，可以把近期会话带上，计划也不会在无人确认时执行。
来源：https://github.com/MoonshotAI/kimi-code/releases/tag/@moonshot-ai/kimi-code@2.4.0

字节豆包
火山方舟Agent Plan的kimi-k2.7-code今日14:00停止服务
火山方舟公告写明，Agent Plan中的kimi-k2.7-code于10月13日10:00发出通知并停止向新用户提供，10月28日14:00正式下线。Small套餐建议迁到kimi-k2.8-preview，其他套餐迁到kimi-k3。同一页的kimi-latest仍对应kimi-k2.7-code，配置了这个模型名或该别名的调用需要到控制台核对。月之暗面自己的开放平台文档仍写，K2系列从10月31日起停止向新注册用户开放，并计划在12月底全部下线。
来源：https://ark.volcengine.com/region:cn-beijing/docs/agent-plan-personal-model-deprecation-announcement

MiniMax
开源MCode Stack，放出团队写MiniMax Code时用的15个Skill
10月28日，MiniMax在GitHub公开mcode-stack，说明这是团队用MiniMax Code开发MiniMax Code时每天在用的工作流和Skill。首份来自研发负责人Ronny的stack含15个SKILL.md，覆盖是否把任务拆给subagent、上下文开销、长会话、长命令和代码审查，许可为MIT。可装进MiniMax Code，通用SKILL.md格式也能放进其他支持该格式的agent。桌面端添加插件市场仍在逐步开放。同日仓库还放上了另一位成员的stack。编程代理可以把这套检查装进日常流程。
来源：https://github.com/MiniMax-AI/mcode-stack
