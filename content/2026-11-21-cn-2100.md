今日要点：11月21日15:54，腾讯混元发布 MemHub v1.0.8 的 GitHub Release，稳定通道，构建号 49。安装包含 macOS 13.0 及以上的 arm64 应用和 Runtime，以及 Linux x64、Linux arm64 的 Runtime。16:27，npm 上 memhub-cli 的最新版本改为 1.0.8。11月20日核对时，1.0.8 只有 git 标签，Release 和 npm 仍是 1.0.6。

腾讯混元
MemHub 1.0.8 安装包发布
11月21日15:54，Hy-Memory 仓库发布 GitHub Release v1.0.8。发布说明写，这是稳定通道的 MemHub 1.0.8，构建号 49，把 Core 钉在 hy-memory 2.0.17，带上离线的 Qdrant/bm25 资源，并加入要在写入停止后才能执行的 bm25-maintenance。安装包为 macOS arm64 的 DMG，系统要求 13.0，另有 macOS arm64 Runtime，以及 Linux x64、Linux arm64 的 Runtime。11月21日16:27，npm 上 memhub-cli 的最新版本改为 1.0.8，命令名是 memhub、memhub-cli 和 one-memory。
背景：11月20日简报写过，当天 11:30 打上 v1.0.8 标签，GitHub Release 和 npm 仍是 1.0.6。这次新的是安装包和 npm 包已经发出。
实际影响：从 GitHub Release 下载，或用 npm 安装 memhub-cli，拿到的是 1.0.8。macOS 应用是 arm64，需要 macOS 13.0。Linux 有 x64 和 arm64 两份 Runtime。
来源：https://github.com/Tencent-Hunyuan/Hy-Memory/releases/tag/v1.0.8
来源：https://www.npmjs.com/package/memhub-cli/v/1.0.8
