月之暗面 Kimi
公开 Hosted Agents 的官方 Go SDK 和命令行 kha 0.5.0
11月16日22:01（北京时间），月之暗面在 GitHub 放入 kha 0.5.0，这是该仓库的第一次提交。它是 Kimi Hosted Agents 的官方 Go SDK 和命令行，许可为 Apache 2.0。SDK 用 Go 1.27 及以上，模块名 github.com/MoonshotAI/kha。命令行提供 macOS、Linux、Windows 预编译包，安装脚本默认从 https://ha-static.moonshot.cn/kha 下载。任务在云端按轮次运行，本地客户端断开不会停。Agent 每次修改生成不可变新版本。Environment 可以是托管沙箱，也可以是自有机器上的工作队列。Session 可挂文件、凭据库和共享记忆，交付物可以发布为带版本的 Artifact。
背景：11月5日已经宣布 Hosted Agents 正式发布。这次新的是官方客户端和源码可以下载。
实际影响：账号要先开通 Hosted Agents，并在开放平台创建 API Key。预编译命令行不必安装 Go。更新日志还没有 0.5.0 的变更条目，这一版就是首个公开快照。
来源：https://github.com/MoonshotAI/kha/releases/tag/v0.5.0
来源：https://platform.kimi.com/docs/hosted-agents/overview

监管
美国公布第三国先进AI芯片的出口许可证要求
11月16日，美国商务部公布临时最终规则。向印度尼西亚、马来西亚、新加坡、泰国或巴西出口先进AI芯片，需要美国出口许可证。向总部设在中国的企业提供大量算力的海外数据中心，须在90天内取得许可证，才能继续提供服务。总部在美国并满足申报要求的企业，向这五个国家出口可以不另申请。网络零售和社交媒体所用的商业推荐系统，不在这条算力限制里。同一规则废止此前未执行的拜登政府AI扩散规则。
背景：联合早报称，阿里巴巴和字节跳动等中国科技企业的算力需求，推动了马来西亚和泰国等地的数据中心扩张。
实际影响：总部在中国、靠上述国家的美国先进芯片训练模型的机构，现有远程算力要在期限内拿到许可证。联合早报称，新措施预计11月19日在《联邦公报》刊登后生效。
