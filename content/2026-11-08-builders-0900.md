今日要点
Tibo 称已把 Pro 与 Business 100 的用量翻倍，呼应用户感觉 Codex 额度更耐用。Karpathy 用 Claude Code 三分钟做出 TristanTube：把 Tristan 的 YouTube 分级清单做成约 4.7 万条极客视频站，带 TV 模式。Garry 的 Hosted GBrain 现在会在同事的 AI 动用你接入的账号前先问你；他还删掉了 /investigate skill，因为 Opus 5.5 不用它也做得更好。他另称赞 Aside Computer Use 用的是几乎不会被网站拦截的真 Chromium。

Tibo / Codex：Pro 与 Business 100 用量翻倍
1. 有用户问：自从 Tibo 不再发放 reset 之后，Codex 用量限制是不是更耐用了。Tibo（@thsottiaux）回复：「We doubled the usage on Pro plans and Business 100」。这条里他没有给出具体 token 数或生效时间表。
背景：提问针对的是 Codex 额度；Tibo 此前有过一段时间亲自发放 reset，后来停了。
实际影响：按他的原话，Pro 与 Business 100 的用量额度已翻倍；具体以账号内显示为准。

Karpathy：TristanTube（三分钟 one-shot）
2. Andrej Karpathy 把 Tristan Hume 更新后的 YouTube 频道分级清单做成了 TristanTube：约 4.7 万条「超极客」视频，并加了适合放松看的 TV 模式。他写：「One-shotted with Claude Code in 3 minutes」。清单原文在 Tristan 的站点上。
背景：11 月 2 日简报已报过他用 Opus 5.5 约两小时做出 HackerTube（从近 20 年 HN 评论里筛出反复被推荐的视频）。这次是同一类「看不顺眼推荐就自己做个播放器」，但原料换成现成分级清单，耗时压到约三分钟。
实际影响：想仿做垂直视频站的人可直接看 TristanTube 和 Tristan 的清单；也是「结构化清单 + coding agent」能压到几分钟的例子。

Garry / GBrain：同事的 AI 用你的账号前先问你
3. Garry Tan 转发 Hosted GBrain 更新：公司「集体大脑」里最大的凭证问题之一，是你能用自己的账号、别人未经允许用不了你的。GBrain 官方说明：GBrain Teams 现在会在同事的 AI 触碰你接入的任何账号之前先征求你同意；「共享 AI 大脑只有在收件箱仍属于你时才成立」。
背景：团队工作区会接入邮箱等账号；共享 agent 若默认可读同事连接的邮箱，凭证边界会立刻出问题。
实际影响：在 Hosted GBrain 团队工作区里，别人的 AI 要读你接入的邮箱或账号，须先获得你的许可。
https://x.com/garrytan/status/2118908444166263106
https://gbrain.io/notes/team-workspaces-ask-before-they-use-an-account

Garry：用 eval 驱动 skill，Opus 5.5 让他删掉 /investigate
4. Garry 写：agent skill 必须做 eval-driven development loop；模型一代代变强，就可以删掉不再需要的 skill。他刚删掉 /investigate，因为 Opus 5.5 不靠这条 skill 也做得更好。「You can feel the AGI tide rising」。
背景：skill 常是为补模型短板加上的固定流程；模型变强后，旧 skill 可能变成多余步骤，甚至碍事。
实际影响：维护 agent skill 的人可定期用新模型跑一遍 eval，主动删掉模型已经内化的流程，而不是只做加法。
https://x.com/garrytan/status/2118920030243139596

Garry / Aside：Computer Use 用真 Chromium，站点更难拦
5. Garry 称赞 Aside 的 Computer Use「非常惊人」，并指出一个额外好处：它用的是真正的 Chromium 浏览器，几乎没有网站能拦。Aside 官方介绍：浏览器里能做的约占工作的 80%，Computer Use 覆盖剩下的部分；称内部评测比 Codex 快 2.7 倍、少用 65% token（这是 Aside 自己的内部评测，不是独立复现）；可在后台跨多个 macOS 应用运行；现已在 Mac 和 Windows 上线。
背景：不少 computer-use 方案用自研浏览器或自动化层，比较容易被网站识别拦截。
实际影响：需要操作系统级、跨应用 computer use 的人可对照这一思路；选型时应把「是不是真 Chromium、会不会被站点拦截」算进评估。
