智谱 GLM
GLM-5.4 向 Coding Plan 全量开放
11月23日，智谱发布 GLM-5.4，即日起向 GLM Coding Plan 全部用户开放。官方博文列出 Coding Plan、ZCode 和 Z.ai 对话；AutoClaw 同日写明已接入，V2、V3 和团队版在 AutoClaw 里使用的额度是 1.5 倍。第一财经报道同步上线 Trae、WorkBuddy、Qoder。这是智谱第一代采用 Loop Transformer 的旗舰：在 750B 规模的 GLM-5 基座上，把 28 层权重共享、循环执行两轮，不靠增加参数来加深计算。官方称智能水平相当于 2T 到 3T 参数的模型，并带上视觉和泛 Coding 能力。非高峰最高约 200 token/s，高峰约 70 到 80 token/s。官方写它容易陷入过长的思考循环，而这种延长的自我修正会提高准确率。标准 API 在安全评估完成后开放，权重计划在完成安全加固后开源。官方并称下一个模型规模显著更大，很快发布。
背景：套餐里仍同时提供 GLM-5.3 和 GLM-5.3-Flash。循环层是把已经预训练的基座继续训练改出来的，不是从零预训练。
实际影响：文档写 GLM-5.4 支持 1M 上下文，并建议把客户端窗口设为 512000。当前积分套餐的抵扣系数是输入 4.6、缓存命中 1.1、输出 16，GLM-5.3 是 6.9、1.7、24。历史 V2 套餐写明 GLM-5.4 按非高峰 0.67 倍、高峰 2 倍消耗额度，GLM-5.3 是 1 倍和 3 倍。高峰是周一至周五 14:00 到 18:00。标准 API 还不能调用，权重也还不能下载。

ZCode 4.0.0 发布
11月23日16:14，GitHub 发布 ZCode v4.0.0。更新日志的日期是 11月23日，没有写到钟点。GLM-5.4 已在 Coding Plan 上线并预置。插件商店按登录地区展示插件。配置服务不可用时，工作流仍可按需启用。文档、表格、演示插件不再做额外的视觉验收。修复包括会话启动长时间卡住，以及切换模型或服务商后上下文偶发丢失。
背景：上一版更新日志是 11月22日的 3.19.1。模型本身的额度和开放范围见上面一条。
实际影响：安装包覆盖 macOS arm64、macOS x64、Windows arm64 和 Windows x64。升到 4.0.0 后，ZCode 里已经预置 GLM-5.4。

腾讯
微信视觉公开 WeMM-Ecom 权重
11月23日17:41至17:59，腾讯微信视觉把 WeMM-Ecom 的 BF16 权重上传到 Hugging Face，覆盖 0.8B、2B、4B、9B 和 35B-A3B。同日继续上传 FP8、GPTQ 和 GGUF。35B-A3B 是混合专家，总参数 35B，激活约 3B，上下文 262144，输入文字、单图、多图和视频。模型卡写支持思考模式，检查点默认是思考模式。权重许可是 Apache 2.0，LICENSE 里列出的第三方组件沿用各自的原许可。Transformers 示例要求 transformers 5.2.0 及以上。
背景：这五个仓库在 11月18日建立，当天只有初始提交。11月20日公开的是另一系列 WeMM-Video。这次新的是电商理解这一系的权重可以下载。
实际影响：上述五个体量的 BF16，以及 FP8、GPTQ、GGUF，都可以从 Hugging Face 下载。核对时 github.com/Tencent/WeMM-Ecom 返回 404。
来源：https://huggingface.co/tencent/WeMM-Ecom-35B-A3B

MiniMax
MiniMax Bot 0.7.34：重试成功后清掉未送达标记
11月23日11:42 合并，插件版本 0.7.34。一条消息投递失败后被标成未送达，用户点重试并且回复已经回来，标记仍停在失败。这一版在宿主接受重试回合之后，顺着 sourceMessageId 找到那条用户消息，把它改成已送达。只改仍然带着第一次失败判定的消息。群聊里由别的 Bot 接力、没有这条关联的回复，这次没有处理。
背景：11月20日的 0.7.33 修的是排队中的任务可以停止，以及写盘失败不再带走进程。
实际影响：直接回答的那条，重试成功后不再挂着未送达。
来源：https://github.com/MiniMax-AI/MiniMax-Code-MiniApps/pull/147

时区守卫 1.0.3：相差两天时显示前天或后天
11月23日12:14 合并，插件版本 1.0.3。两个城市的日历日期相差两天时，页面改为显示前天或后天。相差一天仍用原来的昨天、明天。同一天不加日期后缀。
实际影响：时差大到跨两个日历日的城市，不再被标成明天或昨天。
