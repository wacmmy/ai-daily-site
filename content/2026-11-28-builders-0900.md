今日要点
Swyx 引用 Mitchell Hashimoto 的帖子称，Superlogical 的 Rex 已上架 App Store，首日就「胜过 Cursor 和 t3code」。Rex 是装在 iPhone 和 iPad 上的终端与 coding agent 伴侣应用，需要在电脑上运行 Rex Server。Thariq 提出，模型不应只看排行榜，而应像 RPG 能力表那样分项打分，并用 Claude 与 Codex 生图作了对比。Ryo Lu 发长文认为，通往不可控自我改进的竞赛并非必然，呼吁在难处放慢、对必须承受结果的人负责。Guillermo 推荐 unkernel.dev：把真正的 Linux 内核编译到 WebAssembly，可在浏览器标签里跑完整发行版，还能跑 coding agent，甚至 Chrome 套 Chrome。另外，Nikunj 放出了完全本地的 iMessage / WhatsApp Wrapped 2026；Latent Space 更新了 G2i 训练数据市场访谈，并补报昨天边界前未收的 Clay GTM agent 一集。

Swyx：Rex 已上架，称首日就胜过 Cursor 和 t3code
1. Swyx（@swyx）在 11 月 27 日 14:29（上海时间）引用 Mitchell Hashimoto（@mitchellh）的帖子并评论：「beating cursor and t3code on day 0. strong start」。Mitchell 的原帖发于 11 月 27 日 4:17（上海时间，早于昨天 09:00 那一轮）：Rex 已在 App Store 上线，但需要在另一台设备上运行 Rex Server；他认为这或许意味着完整公开发布临近，并让大家先看启动动画和截图。App Store 页面把 Rex 归在 Developer Tools，开发者是 Superlogical，介绍写明：可把 Mac、Linux、Windows 机器上的终端会话放到 iPhone 和 iPad 上查看、输入和切换；会话仍在电脑上运行，用来查看 coding agent 进度、回应提示或批准命令，也可在手机或平板与 Mac 之间交接窗格。配对方式包括扫描二维码或按地址添加主机。Swyx 说的「胜过 Cursor 和 t3code」是他的判断，帖子没有给出可核对的评测数据和口径，这里不写成已证实的基准结果。
背景：近 7 天 Builders 简报没有报过 Rex。Mitchell 的上架帖比昨天 09:00 那轮更早，当时未收；Swyx 的评论在本轮窗口内，一并补上产品事实。
实际影响：想在外出时盯本地 coding agent 或远程终端的人，现在可以从 App Store 安装 Rex 客户端，但必须先在电脑上跑 Rex Server；完整公开展开仍未宣布。

Ryo：AI 竞赛并非必然，人不应只在旁边看
3. Ryo Lu（@ryolu_）在 11 月 28 日 2:28（上海时间）发长文，开头是「the race is not inevitable」。他写，去年模型还不够强，他必须盯住每个细节，工具帮忙、人来开车；现在角色对调，更多是描述需求然后看成品回来，「we used to drive our dreams. more and more, we just watch。」他担心竞赛指向递归自我改进，直到人不再理解、也不再开车。实验室抢先的理由包括：别人可能更不谨慎、公司要活下去、已经投下太多钱，于是把没人真正想要的结局称为「必然」。他引用庄子，主张大知从容、在难处放慢，并写道，克隆羊三十年后也没有去克隆人——可以放慢、转向、决定某些东西不值得做。他希望做这些系统的人走出来，对必须承受结果、却不在房间里的人负责。
背景：这是个人评论，不是哪家实验室的政策声明。近 7 天 Builders 简报没有报过这篇。
实际影响：对正在做 agent 产品或讨论研发节奏的人，这是一篇可对照的立场文字，没有新的产品或接口可跟。
社区讨论：Thariq 在 11 月 28 日 6:06（上海时间）回复 Ryo，称「this is so beautiful」，并写：驾驭超级智能的方式有很多，「let us not settle for one that disempowers us」。这是他的表态，不是对原文的逐条核对。

Guillermo：浏览器标签里能跑完整 Linux，推荐 unkernel
4. Guillermo Rauch（@rauchg）在 11 月 28 日 4:41（上海时间）发帖，推荐 https://unkernel.dev 。他写这「absolutely unreal」：在浏览器标签里跑完整的 Linux 内核和发行版，「No tricks. The full thing.」可以跑 coding agent，甚至 Chrome 套 Chrome，而且很快。站点自己的说明是：把真正的 Linux 内核编译到 WebAssembly，可在不到一秒内启动到 shell。页面可选用 Debian 或 Alpine，能调 CPU 和内存，数据盘存在浏览器里，源码在 https://github.com/pithings/unkernel 。这不是 Vercel 的产品发布，是他推荐的一个可打开试用的项目。
背景：近 7 天 Builders 简报没有报过 unkernel。
实际影响：想在浏览器里直接试 Linux 环境、或把 coding agent 放进隔离内核的人，打开上述站点即可引导；具体启动耗时会随 CPU、内存等设置变化，这里只转述项目说明和 Guillermo 的体验，不另测。

Levie：扩散容易停在第一层收获，落地仍需要系统改造和 FDE
6. Aaron Levie（@levie）在 11 月 28 日 2:54（上海时间）引用他人关于「普通用户并不知道 agent 能做什么」的帖子，把这概括为扩散（diffusion）的挑战和机会：多数人会停在最初让自己惊艳的用法上，缺少动力走向下一层生产力；很多组织也会在「对已有 AI 收益感到满意」之后停住，还没等到能在后台干活的 agent，或能处理复杂、含糊问题的 agent swarm。他认为这很大程度上是因为把这些架构落地仍很难：尽管使用体验在简化，仍要做大量系统工作、数据管道、MCP 和安全；做完这些，还得重新设计工作流才能拿到全部好处。所以，能尽早想通的组织会有机会；大多数公司自己做不了，眼下也会出现大量服务和 FDE（前线部署工程师）需求。
背景：11 月 26、27 日的简报已报过他关于公司内部 10 倍采用差距、以及用 agent 重做服务业的判断。这篇新在「扩散会停在早期收获」，以及落地所需的系统与流程改造，并明确提到服务和 FDE 机会。
实际影响：在做企业 agent 落地或 FDE、服务业务的人，可以把「用户停在第一层用法」当成需要主动拆的障碍，而不是等能力自己扩散。

Nikunj：本地脚本做 iMessage 和 WhatsApp 的 Wrapped 2026
7. 实际影响：有 Mac、并愿意先读脚本再授权磁盘权限的人，可以按站点说明生成本地年度回顾。页面强调数据不离开这台 Mac，是否如此仍取决于你自己检查脚本。

Latent Space：G2i 谈实验室如何买训练数据，今年收入大约 1 亿美元
8. 补报：Latent Space 访 Clay，GTM agent 要对内对外 harness 一视同仁
9. 补报：Latent Space《How Clay Builds GTM Agents — Jeff Barg, Head of AI》发布于 11 月 27 日 6:44（上海时间），略早于昨天 09:00 那一轮，当时未收，这里补上。节目约 72 分钟。Clay 的 AI 负责人 Jeff Barg 谈到，他们希望无论用 Clay 自带 agent，还是把 Claude Code 指到 Clay，结果大致相当；当前用量已在自带 agent 和外部 harness 之间接近对半。Jeff 是 Clay 收购他联合创办的 Avenue 之后加入的，当时 Clay 大约 50 人、Avenue 5 人；此后业务大约增长 10 倍，团队大约 600 人。今年 9 月 Clay 融资 1.15 亿美元，估值 71 亿美元。按他的粗算，用 TypeSafe 的 Jev 这类分类器，把 Clay 库里约 4000 万家公司对照理想客户画像过一遍，大约要 1500 美元；线索合格评测里，模型已经「考满分」约一年，他认为更值得把前沿模型用在编排和深度研究上。客户不想自己选模型，Clay 计划代选。团队的 agent 仍跑在自己用 BullMQ 搭的系统上，没有用 Temporal 或 LangGraph。节目还谈到，OpenAI 曾在两天前取消 Clay 的 ChatGPT apps 上线。Sculptor 最初是 2025 年 9 月在 Sonnet 3.5 时期上线的工具循环，后来改成基于 Pi harness 的 coding agent，在云沙箱里跑 Clay CLI，并用名为 Audiences 的数据层把 CRM 和 Gong 记录对齐。Jeff 认为多数公司过早做 post-training，要先把推理花费做到大约 1000 万到 1 亿美元这个量级，节省才有意义；想在单一领域超过前沿模型仍然很难。他还提到，agent 目前仍不太会给其他 agent 做调试。
背景：昨天 09:00 简报的时间窗大约接到当天早上，这一集刚好处在边界之前，未被收入。
实际影响：做 GTM agent 或企业 agent 平台的人，可以对照「对内对外 harness 一视同仁」、延后 post-training、以及用 coding agent 加 CLI 重建产品这些具体选择。ChatGPT apps 被取消、Jev 尚未投产等，都按嘉宾口述记录，没有更多官方确认。
