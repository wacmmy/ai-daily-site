DeepSeek
开放全家桶应用API，对话里可搜索、读文件和读链接
11月13日晚间，DeepSeek开放全家桶应用API。deepseek-flash在Messages、Responses和Chat Completions里打开对应参数后，工具调用和上下文拼接由服务端完成：非思考模式下可联网搜索网页或图片并附引用；思考模式下可在多步推理中搜索和阅读链接；可上传PDF、Office和图片，提取文本或做图文解析后放入上下文；打开deepseek_read_url后可抓取用户消息里的链接；开启安全校验后审核输入输出，命中风险时返回拒答标识。Search、Fetch、OCR、ASR、TTS也可以单独调用。官方基于这套API开源了演示客户端，可导入DeepSeek历史对话。体验入口是 https://cdn.deepseek.com/chat-demo ，代码在 https://github.com/deepseek-ai/chat-demo 。
背景：10月17日已经开放自研Search和Fetch，调用和模型之间的衔接要自己串。这次是模型在对话接口里自己决定何时搜索、读链接，并补上文件输入、安全校验、OCR和语音。
实际影响：这些对话能力目前只在deepseek-flash上。除token费用外，搜索和网页抓取各为每1000次5元，文件解析和OCR为每1000页1.5元；语音合成刊例价每万字符3元、限时五折1.5元，语音识别刊例价每小时0.78元、限时五折0.39元。对外提供应用时要打开安全校验，并自行承担内容安全审核、大模型登记和AI标识。演示客户端的密钥和历史只留在浏览器本地，导入历史对话会覆盖已有对话。

月之暗面 Kimi
Kimi Code 2.6.2发布，自定义网关可接搜索和反馈
11月14日01:20，月之暗面发布Kimi Code 2.6.2。自定义注册表api.json里，每个提供方可以写可选的search_url和feedback_url。当前模型走这个提供方时，WebSearch和/feedback会发到这两个地址，并复用该提供方的凭证。/feedback去掉了只发文字、不带附件的选项，确认前会列出当前会话目录里的文件，并带上主会话最近一次request_id。Kimi文件上传如果已经返回文件ID，但处理失败或尚未就绪，不再把这个引用缓存下来继续用。Swarm面板在子代理还在执行时会更新成员和完成数。工具调用很多的长会话，重放不再按历史长度做平方级拷贝。网页端另有交互改进和已知问题修复。
背景：11月13日的2.6.1已经修过长会话重开时的多秒加载，以及工具结果带注释时不压缩、空回复卡住。这次的重放修复针对的是工具调用很多的会话。发布说明里写，450轮、约4500次工具调用的服务端重放从约6秒降到约0.07秒。
实际影响：用自有模型网关、没有走托管Kimi账号的，可以在api.json里声明搜索和反馈地址。/feedback不能再只发一句话。处理失败或还没就绪的上传不会再被当成成功文件反复送给模型。开着/swarm时，面板会跟着子任务更新，不必等整个AgentSwarm结束。
