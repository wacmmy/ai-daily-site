今日要点
Claude 将 Max 5x/20x 更名为 Max/Ultra，已验证 Ultra 取消 5 小时限额（周限额不变）。Aaron Levie 称前沿使用者与其他人差距仍在拉大，流程若半年前定死可能已落后。Guillermo 谈开源 coding agent fx 更小更快、未缓存输入 token 降约 41%，以及 Next.js 原生语言（先从 Go Route Handlers）原型。Amjad 发 Agent Habitat 沙箱白皮书，并警示员工笔记本上的 coding agent 是重大安全风险。Garry 推 Particle-1 与 Capy 组合；Peter Yang 整理 a16z 场次七点；Zara 发「不用当设计师也能用 AI 做出有品味作品」视频。

Aaron Levie
2. 前沿使用者与其他人的差距几乎难以想象，且这两条线不是在汇合，而是越拉越远。若 AI 进步曲线已经放平，多数人或公司本有时间追赶、把流程标准化，技术反而会抹平优势；现实相反——曲线近乎垂直，3–6 个月前固化的流程现在可能又落后了，一年前以为「做完了」的公司更落后。他认为这是职业生涯里进步最快的技术，预期与组织变革也要同速上调；递归自我改进下，几个月前行不通的事要不断拿出来再试。AI 原生公司目前优势明显，关键看大公司能否跟上。

Guillermo Rauch
3. fx（tiny/open/native coding agent，Zig CLI）改进速度很快：更小、更快、更省 token；团队持续评测并让它跨开源与专有模型自我优化。对应 vercel_dev 的 fx v0.0.16：更好的 prompt caching、约 41% 更少未缓存输入 token、libfx npm 下载约小 60%、CLI binary 约小 2.8%。另转发 Tim Neutkens：Next.js 在原型原生语言支持，先从 Go 的 Route Handlers 与 Proxy 起步，给 CPU 密集服务端负载更多选项；Guillermo 称「Next Native is coming」。
