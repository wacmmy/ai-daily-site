今日要点
Replit 公开基于 microVM 的新沙箱引擎，自定义内核可规避约 96% 相关 Linux CVE；Amjad 宣布与日本 SMFL 合作加速企业软件交付。Vercel Schedules 公测，agent 可运行时自建定时任务。Cursor 支持描述需求后一键构建、检查并部署可分享应用。Swyx 称 Thinky Machines inkling 蒸馏出 SWE-2 Flash：更快更便宜、评测持平。Aaron Levie 推 Box×NVIDIA 上下文检索与 Architect/Mount，服务企业非结构化数据上的 agent。

Replit 沙箱引擎（microVM）
1. Replit 工程博客《Inside Replit’s New Sandbox Engine, Part 1》披露：过去数月已完成沙箱引擎重写并平滑迁移数亿项目。新方案用 KVM + Cloud Hypervisor，每个沙箱自带 Linux 内核的 microVM；容器仍做沙箱内隔离。客内核从 tinyconfig 裁剪，禁用模块加载。团队审计 2026-06-01 至 11-04 的 6211 条 Linux-CNA CVE，称通过及时合入上游修复或配置排除，规避约 5969 条（96.1%），其中约 70% 修复在披露前已落地。Amjad 转发：「on Replit we’re able to avoid 96% of them with our custom Kernel build。」获取沙箱（含挂盘）约 500ms；凭证经 host 侧 broker，工作负载拿不到可复用账号密钥。
背景：共享宿主机内核的容器一旦逃逸影响面大；agent 自主性升高后，隔离与凭证外置成为标配讨论。
实际影响：做 agent 沙箱的人可对照「独立 guest 内核 + 最小攻击面 + 凭证不进 guest」；Replit 用户侧已在用这套引擎。

Amjad / Replit × SMFL
2. Amjad 宣布与日本三井住友融资租赁（SMFL）合作：Replit 已支撑 SMFL 核心软件产品；举例称对方一人一周完成原先六人、六个月的项目。下一步要把 AI 驱动的软件创建带到日本企业，应对人力短缺与加速创新。
背景：继其「托管云端 agent 为默认」安全主张后，这是企业落地合作案例。
实际影响：日本大型金融机构把 Replit 写进核心交付链路；可作为「一人+agent 替换小团队交付」的对外数据点。

Vercel Schedules
3. Vercel Schedules 进入公测（全套餐）：可在生产/预览/自定义环境跑周期性或一次性任务；`vercel.json` 定义静态任务，运行时 SDK/CLI 可动态创建（动态任务打到 Queue topic）。目标可以是私有 Function、HTTP path 或 Queue；可启停与按需触发。Guillermo 转发称「Doing stuff for you over time」是 agent 杀手级能力，举例 Muse/Instinct 夜间整合记忆、早晨提醒、N 天未互动再发消息；Schedules「像加强版 Cron」，可运行时定义、无限扩展，且在 Sandbox 外，按需调算力更省。接替 Cron Jobs，旧 Cron 仍可用。
背景：agent 需要「隔一段时间再做事」，但多数 cron 不能由 agent 运行时自建。
实际影响：做长期 agent（提醒、夜间巩固、preview 里测定时流）可直接用 Schedules，不必自搭调度。

Cursor 一键部署
4. Cursor 官方：可在 Cursor 里构建 live app 并用链接分享。描述想要的工具后，Cursor 会构建、建库、跑确定性与 agentic 安全检查并部署；多数应用此前停在 localhost。Vercel 称基于 Vercel for Platforms：无需另开账号、无需手写部署配置、含数据库开通。Guillermo 总结闭环：X 订阅 → Bot/Cursor 构建 → 部署 Vercel → 在 X 分发 → X Money/Creators 变现，「The loop is nearly complete」。
背景：写代码已便宜，卡点常在「出 localhost」。
实际影响：个人/小团队可从描述直接到可分享 URL；与 Vercel Platforms 绑定。

Swyx / Thinky Machines inkling
5. Cognition 发布 SWE-2 Flash（更快、更省的编码模型），称在领先评测上超过所有美国开源权重模型（含约 3 倍大的）。Swyx 引用后评论：3 倍速、5 倍便宜，但 FrontierCode 2 评测持平——「distillation without tradeoffs」；认为 @thinkymachines 的 inkling「是世上最被低估的基座之一」，预期美系预训练模型上会出现大量类似蒸馏产物。
背景：名单内 Swyx；inkling 作蒸馏基座的说法来自他本条判断，非独立评测复现。
实际影响：选型时可把「同评测档、更便宜更快的蒸馏码模型」放进候选，并关注权重安全分享计划。

Aaron Levie / Box × NVIDIA
6. Aaron Levie 发长文并在帖中强调：企业里 agent 数量将远超人（他写到约 100 倍量级），部署成败取决于能否拿到决策/研究/执行所需上下文；约 90% 企业数据是非结构化内容。BoxWorks 上宣布四项：① Box Architect——用前沿模型自主设计、测试、优化内容侧工作流；② 与 NVIDIA 合作的 Context Retrieval（词法+语义混合检索，遵守权限），内部测称准确率约 +20%、token 效率约 +90%、回答约 4 倍快；③ 即将推出的 Box Mount，让 agent 在沙箱里直接读写 Box 文件夹（对接 OpenShell、DigitalOcean、Daytona、E2B 等）；④ Shield 侧加强威胁检测与 agent 安全管控。另发短帖呼应「100X more agents… Files 🤝 GPUs」。
背景：接续他近几日「管一队 agent / 产出差距拉大」的讨论，落到企业内容平台产品。
实际影响：企业要接 agent，可优先看「权限内混合检索 + 沙箱挂载文件系统」，而不是只塞聊天窗口。
