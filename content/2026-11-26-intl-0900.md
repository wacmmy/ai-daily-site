2. （补报）MCP 服务器可以附带 skills，Tasks 和 Elicitation 正式可用，上一轮简报未写。文章日期为 11 月 24 日。Skills over MCP 在 Claude 和 Claude Code 进入公开测试。服务器把技能和工具一起发布，Claude 只在需要时加载，使用者不必另外安装。Pro、Max 和 Ultra 默认打开。Team 要管理员打开。Enterprise 即将支持。文中已在用的例子有 Shopify、HubSpot 和 Atlassian。Carta 即将用它根据上传的文件起草股权。Tasks 和 Elicitation 对 Pro、Max 和 Ultra 在 Claude 和 Claude Code 正式可用，并正在向 Team 和 Enterprise 推出。Tasks 让服务器在后台跑耗时操作，Claude 可以继续做事，ZoomInfo 用它做账户和联系人调研。Elicitation 让服务器中途用表单或链接请用户确认后再继续。Supabase 在创建付费项目和运行破坏性 SQL 之前确认费用。Railway 在可能造成破坏的改动前询问。GitHub 在智能体删除仓库前要求输入仓库名。File Uploads 即将向 Pro、Max、Ultra，以及符合条件的 Team 和 Enterprise 推出，把 PDF、表格和图片直接交给服务器，不经过上下文窗口。

3. （补报）Artifacts 可以安装成 Mac 和 Windows 应用，上一轮简报未写。文章日期为 11 月 24 日。The Verge 于 UTC 11 月 24 日 23:04 报道，合上海时间 11 月 25 日 07:04。Install as app 在 Claude 的 Mac 和 Windows 版以测试形式推出。装上之后有自己的图标和窗口，不在 Claude 里面打开。应用可以使用 Claude 和已连接的服务，这些请求计入套餐用量。权限分三档。默认只做浏览器里能做的事。应用权限可以申请通知、全局快捷键或置顶窗口。完全访问计算机之后，可以运行程序，并在不再逐次询问时读取、修改或删除文件。完全访问只给自己做的应用；Team 和 Enterprise 还可以给组织里其他人做的应用。授权只覆盖当前版本，每次更新，包括自己的修改，都要重新确认。应用里如果有来自别的网站的部分，那一部分可以在不再询问的情况下改变。Anthropic 在安装前不审核应用。所有套餐都在推出。已准备好 HIPAA 的组织和混合部署不能用。Team 默认打开，完全访问默认关闭。Enterprise 要所有者打开才可用。必须在线并登录 Claude。Claude Docs、Slides 和 Sheets 不能安装。入口是 Share 菜单里的 Install as app。
实际影响：Enterprise 默认是关的。页面写，完全访问只应给信任的作者。

4. （补报）Claude Code 2.1.332 发布，上一轮简报未写。发布时间是 2026-11-25 01:32 UTC，合上海时间 11 月 25 日 09:32。来自 MCP 服务器的 skills 以测试版出现在斜杠菜单里，显示为 server:skill。新增 PreSkillShellCommand 钩子，可以在技能或命令加载时拒绝其中的内联 shell。2.1.331 及更早版本如果设置文件写了这个事件名，启动时会弹出对话框。点按语音听写的停止条件放宽：终端改为 60 秒没有新词，或满 10 分钟；VS Code 改为 60 秒没有识别到语音，或满 10 分钟。原先都是 15 秒和 2 分钟。Bedrock Mantle 上的 sonnet 别名改为 Sonnet 5，不是 Sonnet 5.5；账号没有 Sonnet 5 会报错。Google Cloud 的 Agent Platform 和 Microsoft Foundry 上的 sonnet 改为 Sonnet 5.5，Foundry 的 opus 改为 Opus 5.5。Amazon Bedrock 上的 sonnet 仍是 Sonnet 4.5。Foundry 的默认模型改为 Sonnet 5.5，要部署 claude-sonnet-5-5，或设置 ANTHROPIC_DEFAULT_SONNET_MODEL。在 Bedrock Mantle、Agent Platform 和 Foundry 上，终端和 VS Code 会话如果切到 Sonnet 5 或 5.5 且没有设定模式，会以 auto mode 启动；把 disableAutoMode 设为 disable 可以关掉。在打开了 computer use 的 Mac 上，computer-use 成为保留技能名，同名的自有技能或命令不再加载。自托管运行器的 OAuth 令牌前缀除 oat01- 外，也可以是 oat02-。同版还修了多处终端、MCP 和远程控制卡住或误报用量上限的问题。
背景：11 月 24 日简报写过，2.1.331 的点按听写在 15 秒没有识别到语音或到达 2 分钟后自行停止。这次把这两项上限放宽。MCP skills 的推出范围见上一条。
实际影响：还在用 sonnet 或 opus 别名，并且走 Foundry、Agent Platform 或 Bedrock Mantle 的人，更新后别名指向的模型版本会变。Foundry 上如果没有部署 Sonnet 5.5，也没有改默认模型变量，默认模型会找不到。Mac 上名叫 computer-use 的自有技能要改名。代理或日志规则如果只匹配 oat01-，要加上 oat02-。

5. 公布 Messages API 从 Python 迁到 Rust 的做法和测量。文章日期为 11 月 25 日。页面记录的创建时间是 UTC 11 月 25 日 05:15，合上海时间 13:15。官方账号于上海时间 11 月 26 日 00:26 发帖。Messages API 是客户以及 Claude Code、Cowork 调用 Claude 的主要入口。页面写，公开流量在 2026 年 9 月切到 Rust。迁完后，每个请求的 CPU 大约少 70%，每个请求的内存少 80% 以上，客户 Claude Code 请求的中位首 token 时间大约少 20%。切换时服务没有下线，功能开发也没有冻住。从 2024 年初到 2026 年秋，自有平台上的 API 流量大约增长到 1800 倍。Claude 大约用一周写出核心请求路径的第一版。核对时不读取客户请求和 Claude 的回复，只记录差异出现在哪一步、提示词的哪一段，以及两边差多少字节，再交给 Claude agents 分组修复。4 月时 Rust 版大约通过 98% 的测试，但在当时比较的生产流量上，只有大约四分之一的输入与 Python 一致。
实际影响：页面写公开流量已在 9 月切换。调用 Messages API 的人没有新的模型名或开关。上面的 CPU、内存和首 token 时间，是这次帖文公布的测量，不是今天才切换。

6. Antigravity 放出 Mass Spec Skills。DeepMind 博客的发布时间为 2026-11-25 17:00 UTC，合上海时间 11 月 26 日 01:00。这是一组领域技能，把 Gemini 的化学推理和已有的质谱工具、公共化学数据库接在一起，用来解释串联质谱、列出化学证据，并排出候选结构。已收录在数据库里的分子，识别会快得多。还没有被收录的分子，智能体可以缩小分子式和碎片所支持的结构部分，不能自行确认全新结构。镜像异构体和一些相近异构体单靠液相串联质谱分不开，还要保留时间、离子迁移率或核磁共振。技能今天可以在 Antigravity 里安装 Mass Spec 插件后使用。企业用户选择 Use Business Account，用 Google Cloud 账号登录。在 100 个已经有公共参考谱、并且结构也在 PubChem 里的化合物上，加上这些技能后，Gemini 3.8 Flash、Gemini 4 Argon 和 Gemini 4 Carbon 把分子精确识别并核对出来的比例大约都是 97%。不联网、也没有技能时，三款都低于 4%。同一批运行里，技能把每次尝试生成的 token 降下来：Flash 将近少到四分之一，Argon 大约少一半，Carbon 将近少五分之一。
背景：11 月 4 日简报写过 Antigravity 的 Science 插件，用 RDKit、ChEMBL 和 PubChem 做化学信息学。同一篇也写过，符合条件的科学家可以申请六个月免费的最高用量档，滚动最多 1 万人。这篇再次写申请开放。这次新的是 Mass Spec 插件。
实际影响：现在能安装的是 Mass Spec 插件，不是一条面向所有 Gemini 用户的新开关。不在数据库里的新分子，页面写只能作为化学家继续做结构解析的起点。
https://deepmind.google/blog/interpreting-mass-spectra-with-google-antigravity/
