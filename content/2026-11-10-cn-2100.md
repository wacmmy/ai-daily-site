今日要点：11月10日，Kimi Code 2.5.3在模型还在输出文字时，插入的消息会打断当前请求，并在同一轮的下一步继续。MiniMax开放平台上线图像模型H3-Image，支持文生图和最多16张参考图的编辑，按token计费，另有极速版。

月之暗面 Kimi
Kimi Code 2.5.3发布，输出途中可打断当前请求
11月10日21:06，月之暗面发布Kimi Code 2.5.3。模型正在输出文字或重试时，有效的steer会中断当前模型请求，已经流出的思考和文本会保留，这条消息在同一轮的下一步被消费。工具调用已经开始生成，或工具已经在执行时，当前请求和工具不会被取消。新增接口POST /api/v1/sessions/{session_id}/steer，一次请求就能提交并steer。Windows上用npx这类脚本命令配置的stdio MCP服务器现在可以启动。
背景：11月6日的2.5.2修的是MCP工具定义变化时，select_tools报重复工具声明。
实际影响：升级到2.5.3后，输出过程中插入的消息不必再等这一步自己结束。工具已经在跑时，steer仍会等到这一步结束。原先在Windows上起不来的npx类MCP可以拉起。
来源：https://github.com/MoonshotAI/kimi-code/releases/tag/@moonshot-ai/kimi-code@2.5.3

MiniMax
开放平台上线H3-Image，编辑最多16张参考图
11月10日，MiniMax在开放平台模型发布页列出图像模型MiniMax H3 Image。标准版调用名是MiniMax-H3-Image，极速版是MiniMax-H3-Image-Highspeed，两边的参数限制相同。文生图使用POST /v1/images/generations，图像编辑使用POST /v1/images/edits，参考图为1到16张。输出面积最大2000万像素，可以指定宽高，也可以按1K、2K、4K面积档和宽高比生成，4K是默认面积档。单次1到10张，格式为jpeg、png或webp。图片链接有效期24小时。不支持预览图、局部遮罩编辑和透明背景。接口是同步的，打开stream后按完成顺序逐张返回。请求不支持幂等：客户端超时或断开后，服务端仍会完成生成，并对成功的图片计费，重试会再生成并再计费。服务端最长等待600秒。
背景：模型列表里image-01和image-01-live仍可用，价格页按张0.025元。H3-Image改为按token计费。
实际影响：标准版文本输入15元、图片输入10元、图片输出25元，单位都是每百万tokens。极速版是15元、20元和50元。价格页在默认提示词增强下给出的参考费用里，标准版4K文生图约为0.4522元一张，页面写明这是参考值，不是固定按张价格。调用时把超时设到不低于600秒，并关闭SDK的自动重试。官方命令行和MCP同一天加入了H3-Image的生成和编辑。
