开源文心 5.5 Flash Preview 权重
11月24日，文心 5.5 Flash Preview 的权重可以在 Hugging Face 下载，许可是 Apache 2.0。IT之家 14:59 报道百度当日宣布开源。三份仓库的权重目录提交时间是11月23日19:53（上海），模型卡在11月24日15:17更新。发布页核对时仍写权重即将以 Apache 2.0 开源，页面日期还是11月11日。默认仓库是块状 FP8 加 MXFP4 专家权重，并带 DSpark 草稿头；另有 FP8 仓库和 BF16 仓库。这是后训练中的中间版本，正式版还会再改。总参数 280B，每个 token 激活 14B，上下文 1M，文本进、文本出。
背景：11月11日千帆已经可以调用 ernie-5.5-flash-preview，当时思考强制开启、不能关，并写明权重将于11月25日前开源。11月5日开源的 Base 停在预训练结束，许可仍是 ERNIE 5.5 Flash Base Model License Agreement v1.0，这次的 Apache 2.0 只覆盖 Preview。
实际影响：没有 FP4 内核时用 FP8 或 BF16 仓库，微调从 BF16 开始。开放权重默认开启思考，模型卡写明可以把 enable_thinking 设为 false 关掉；打开时 reasoning_effort 为 low、medium、high，默认 high。部署可以用 SGLang，或 vLLM 0.32.0 加 baidu/vLLM-ERNIE。

开源翻译模型 Hy-MT3
11月24日，腾讯混元在模型卡的新闻里写明，开源 Hy-MT3-1.8B、Hy-MT3-7B 和 Hy-MT3-30B-A3B，并在同一仓库放出评估方案 TransRubric。语种从 Hy-MT2 的 38 种增到 102 种。官方称在真实场景数据上，误译样本比例降低 43%，漏译或增译降低 74%，指令遵循类错误减少 40%。30B-A3B 激活 3B。每档另有 FP8 和 GGUF。Hugging Face 上的许可是 Apache 2.0。游戏本地化可以接王者荣耀团队的工具链 TiMiHOKGameTranslator。IT之家 17:12 报道，模型已在腾讯 Hy 翻译 App 和小程序上线。

实际影响：三档权重以及 FP8、GGUF 可以从 Hugging Face 或 ModelScope 下载自行部署。TransRubric 在 Hy-MT3 仓库的 TransRubric 目录。

MiniMax
MiniMax Bot 更新到 0.7.37
11月24日15:30 合并，插件版本 0.7.37。群聊里成员没话说就回 [PASS]。先前每一轮都会把这句写成最后结果，于是前面真正说过的话被盖住，交出去的结论文本只剩 [PASS]。这一版让 PASS 那一轮不写最后结果。全员都 PASS 时返回空文本。前面有人说过话时，保留那句。等待子任务，或无法安全继续时，即使回复是 [PASS] 也会停。
背景：11月23日的 0.7.34 修的是重试成功后清掉未送达标记。
实际影响：群讨论交出去的结论文本不再是 [PASS]。作者写明只在 Node 22 上用模拟 Agent 测过，没有在真实 Host 和 Electron 上点过。
来源：https://github.com/MiniMax-AI/MiniMax-Code-MiniApps/pull/153

上线 GitHub 收藏夹小应用
11月24日15:30 合并 GitHub Star Shelf，插件版本 1.2.0。它把 GitHub 星标收成可以搜索的收藏夹，能按项目名、简介、主题、README 和笔记搜索。可以用 gh 导入自己的星标，或按用户名读公开星标。云端讲解只读项目信息和 README，不下载代码。本地讲解会浅克隆到会话自己的工作区，不运行、不安装、也不构建。每个项目单独一个会话。
实际影响：在 MiniMax Code 里从 Git 仓库导入，或把文件夹放到插件目录后重启。本地讲解需要 git。没有 gh 时走 GitHub 匿名接口，每小时 60 次。声明的权限是 session.run。作者写在 MiniMax Code 3.1.16 的 macOS 和 Windows 11 上用真实账号测过。
来源：https://github.com/MiniMax-AI/MiniMax-Code-MiniApps/pull/151

上线论文工作台 FactScribe
11月23日22:10 合并 FactScribe Paper Workbench。这是 MiniMax Code 里的本地论文工作台，打开一个放 LaTeX 稿件的文件夹，稿件可以有几种语言的草稿。页面显示检查报告、事实账本和知识库。数字对不上账本、引用对不上的条目会标出严重程度和位置。助手只能提出修改，要在页面上批准之后才会写进稿件。
