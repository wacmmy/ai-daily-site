今日要点：DeepSeek公开研究原型dsh-superagent，被点名后可自行处理单个代码仓库的任务。MiniMax Code 0.7.2加入默认关闭的程序化工具调用。腾讯云今日0时下线托管的DeepSeek-V4-Flash 0731。豆包电脑版新用户可领30天体验，百度搜索API增强版活动价4.9元/千次，这两条是补报。

DeepSeek
公开研究原型dsh-superagent，面向单个代码仓库
10月31日，DeepSeek在GitHub公开dsh-superagent-prototype。说明写明这是研究原型，不是正式产品，许可为MIT。它作为DeepSeek Harness的一个包，监听GitHub，也可选监听飞书。被允许的人提出任务后，它会建立工作项，在自己的会话和目录里处理，并回到原来的对话回复，例如附上拉取请求。网页面板标出需要人处理的事项。代理只在被点名时行动，或在团队事先写好的规则允许时行动。公开版本已为发表做过改写，与内部版本以及《Exploring Super-agent Design: Towards a More Autonomous Agent System》一文中的实现并不相同，文中部分设计尚未写进这个原型。
来源：https://github.com/deepseek-ai/dsh-superagent-prototype

MiniMax
MiniMax Code 0.7.2上线，多次工具调用可写成一段沙箱代码
10月31日12时，MiniMax在GitHub发布MiniMax Code 0.7.2。更新日志写明新增测试版程序化工具调用，默认关闭。打开后，代理编写一段run_code，把读文件、搜索和命令等调用放进沙箱，只把筛选后的结果带回上下文，适合批量读文件和多步任务。同版在回合结束后给出下一句提示，按Tab即可填入，这项对未做过选择的用户默认开启。插件也可以声明子代理。
来源：https://github.com/MiniMax-AI/minimax-code/releases/tag/v0.7.2
